## 用途

`BaseMaterial` 插件是一个**纯内容插件**，它不包含任何 C++ 代码模块。其核心目标是提供一个**统一的、标准化的基础材质函数与材质层资源库**。这些资源主要包含用于纹理采样、坐标变换和材质混合的基础功能，旨在为美术和开发者提供一套开箱即用的、经过优化的基础材质构建模块。通过使用这些预设的函数和层，可以避免在不同材质中重复创建相同的逻辑，从而简化材质工作流程，确保项目内材质的基础质量与风格一致性。

## 使用场景

*   你在开发一个需要大量复杂地形和材质混合的开放世界游戏，希望使用标准化的函数来处理纹理坐标和法线混合。
*   你正在快速原型设计一个新项目，需要立即获得一些高质量、可定制的基础材质（如草地、石头、金属）作为起点。
*   你的团队希望在不同美术师和开发者之间建立统一的材质制作规范，减少沟通成本和风格差异。
*   你正在学习或教学 UE5 的材质系统，需要一个结构清晰、功能明确的材质函数集作为参考。

## 蓝图用法

作为纯内容插件，其“蓝图用法”体现在材质编辑器中。以下是其提供的核心材质资产（函数与层）的预期用途：

### 核心资产（材质函数与层）

| 资产类型 | 资产名称示例 | 说明 |
|---|---|---|
| 材质函数 | `MF_BaseTextureSample` | 提供标准化的纹理采样流程，可能包含 Mip 偏移、对比度调整等常见后处理步骤。 |
| 材质函数 | `MF_CoordinateTransform` | 一组用于 UV、世界位置、顶点法线等坐标变换的实用函数（如旋转、缩放、平移）。 |
| 材质层 | `ML_BaseGrass` | 一个预设的草地材质层，包含了基于世界位置的纹理混合、风扰动等基础效果。 |
| 材质层 | `ML_BaseRock` | 一个预设的岩石材质层，可能包含法线细节、高度混合和磨损效果。 |

### 使用示例（在材质编辑器中）

1.  **引入函数**：在材质图表中，右键搜索插件提供的函数名称（如 `MF_BaseTextureSample`），将其拖入图表。
2.  **连接参数**：将你的纹理样本（Texture Sample）节点的输出连接到该函数对应的输入引脚（如 `UVs`， `BaseColor`）。
3.  **应用层**：在材质图表的主栈（Main Material Stack）中，右键选择“添加材质层”，然后从资产浏览器中找到插件提供的材质层（如 `ML_BaseGrass`）并应用。
4.  **混合与覆盖**：材质层可以像通常一样被其他层混合或覆盖，利用预设的函数简化了底层逻辑。

## C++ 用法

不适用。此插件不包含 C++ 代码模块，其价值完全体现在其内容资产（`.uasset`）上。

## Demo 示例

此插件本身即为一个示例库。要使用它：
1.  确保插件已启用（默认启用）。
2.  在内容浏览器中导航至 `Plugins/BaseMaterial Content/`。
3.  你将看到插件提供的材质函数 (`MaterialFunction`）和材质层 (`MaterialLayer`) 文件夹。
4.  打开任意一个函数或层资产，查看其内部实现逻辑，学习其用法。
5.  创建一个新材质，在材质图表中像调用其他引擎内置函数一样，调用此插件提供的函数。

## 模块依赖

无特殊依赖（纯内容插件，仅依赖引擎核心材质系统）。

### 维护评价

`BaseMaterial` 是一个**非常新的插件**，于 2025 年 8 月首次提交。虽然它仍被标记为 **Beta 版本**，但最近一次提交（2025年10月）将其默认启用状态更改为开启，这表明 Epic Games 正在积极地推进其测试和集成工作，而不仅仅是创建后搁置。

**优点**：
*   解决了材质制作中常见的函数复用和标准化问题。
*   作为官方插件，其质量和性能预计会得到保证。
*   默认启用，易于被新项目发现和使用。

**考虑**：
*   由于处于 **Beta 阶段**，其中的资产和用法在后续版本中可能发生变更。
*   目前提供的函数和层数量可能有限，需要根据项目需求进行扩展或调整。

**推荐**：对于新项目，特别是希望快速建立规范材质管线的团队，**推荐尝试使用**。它为材质系统提供了一个优秀的起点。对于维护中的老项目，可以评估将部分基础材质逻辑迁移到此插件提供的函数上，以提升一致性。
