# 2026-06-10 引擎周报

## ✨ 新功能
*   为 **RigVM** 增加了对事件节点可变输出引脚的支持。
*   在 **UnrealEd** 中初步提交了 **ModelessTools** 和 **InteractiveVisualizers** 模块，并将其与 **FEditorModeTools** 集成，提供了新的编辑器交互模式基础。
*   新增 **CheatsToolset** 编辑器插件，提供列出并调用本地玩家 Cheat Manager 上作弊命令的 AI 工具集。
*   新增 **EditorAppToolset** 工具，包括通知、缓存资产缩略图、视口显示标志/视图模式和编辑器模式等功能。
*   为 **StateTree** 层级图视图添加了逐过渡引脚，每个状态节点针对每个传出过渡暴露一个输出引脚，针对每个传入过渡暴露一个输入引脚。
*   为 **AIE** 在加载动画或烘焙到控制绑定时添加了“Bale To Interval”选项。
*   为 **FPropertyBagRepository** 的占位符类型创建过程添加了 **DisplayName** 元数据设置。
*   为 **FCameraViewportClient** 添加了 `CalcSceneViewInitOptions` 以支持 **ModularViewport**。
*   为 **AI Assistant WebApi** 添加了 `BypassSignInRequirement` 及相关测试。
*   为 **asset tools** 添加了 `reload_asset` 工具，并优化了工具集描述。
*   在 **Dataflow** 中实现了 **PreviewBP** 功能。

## 🚀 重大变更
*   将 **Lumen** 的 `r.Lumen.IrradianceFieldGather.NumClipmaps` 参数更改为 6，使其在 **Medium Quality** 设置下可覆盖距摄像机 160,000 单位的范围。最后两个 clipmap 会在硬件光线追踪半径或软件光线追踪场景视距较小时被剔除。
*   启动了 **MetaSound Controller API** 向 **Builder API** 迁移的第一阶段。

## ⚡ 性能优化
*   为 **MassCharacters** 注册的 CVars 添加了 **Scalability** 标志，使其可通过 Scalability `.ini` 文件进行设置。
*   **Nanite RT** 现在使用 **RootPageIndex** 代替 **RuntimeResourceID**，以避免因版本位导致的数组过大。
*   重构了 **HWRT/D3D12** 中 **LSS** 代码路径对 **IndexBuffer** 的检查逻辑，并将内联分配器大小减小为 1，因为 LSS 的使用场景并不常见。
*   优化了 **Mover** 组件在提取根运动角速度前强制进行最短弧旋转的逻辑。
*   为 **ToolsetRegistry** 在工具集工具执行时抑制了编辑器 CPU 节流。
*   **PCG**：为网格地形组件的获取添加了延迟处理，并使用网格边界进行过滤。
*   **Mutable**：修复了由于一个 `SK_New` op 流送了超出范围的 LOD 而导致骨骼网格体 LOD 流送挂起的问题。

*   启动了 **MetaSound Controller API** 向 **Builder API** 迁移的第一阶段。
*   添加了 `[at]export_metadata` 编译器基础设施。
*   **PCGExternalDataInterop**：为下游项目构建，在 `PCGLoadAlembicElement.h` 中采用了每方法 **UE_API** 导出模式。
*   将 `llm_session` 重命名为 `ai_session`，将 `llm_prompt_error` 重命名为 `ai_error`，将 `[at]llm_description` 重命名为 `[at]ai_description`。
