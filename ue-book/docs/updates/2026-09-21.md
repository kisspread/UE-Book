# 2026-09-21 引擎周报

## ✨ 新功能

- **Nanite 半透明材质支持**：新增 `r.Nanite.AllowTranslucentMaterials` 运行时开关，支持 Nanite 半透明材质。包括将顶点颜色插值到像素着色器、以 masked 方式投射阴影、遵循双面材质属性，并修复了 raster link 错误和 translucency bin 崩溃。
- **AVBOIT 渲染技术**：为 Nanite 和非 Nanite 半透明引入 Adaptive Voxel-Based Order Independent Transparency（AVBOIT），提供新的顺序无关透明渲染方案。
- **Shader Compilation 增强**：支持 mesh shader 输出属性中的嵌套结构体，更新 DXC 二进制以包含对应修复；同时临时禁用 dual source blending 的 SPIRV decorations，解决 ABVOIT permutations 中的 `partial explicit stage output location assignment` 错误。
- **UAF 扩展**：将 UAF Transitions 暴露给 Blueprint，为 transition nodes 添加 source/target accessors，新增 overlay modifier base class 以简化 anim node modifier 创作，并支持 proxy asset output structs 绑定 UAF output variables。
- **AIE Smart Compensation 新能力**：新增 `Sequencer.SwitchBoundary.OccupiedLandingMode 3` 模式，在移动 switch key 时保持现有世界位置并动态调整偏移；同时增加 Paste 命令、Save Whole Pose 命令，并集成到 Utility Tab Spawner。
- **PVE Mesh LODs**：为程序化植被添加网格 LOD 支持，包含 asset version stamp 和 node deprecation gating。
- **Control Rig 编辑增强**：在 rig 首次构建时创建 control shape actors；支持在视口中 marquee 选择 sockets 和点击选择 nulls；Anim Details 面板现在展示 proxy control 下父级的 Animation Channels。

## ⚡ 性能优化

- **Substrate 光照优化**：当没有 rasterized lighting pass 会读取 standalone tile stencil 时（例如所有灯光均由 MegaLights 处理），跳过该 stencil pass，减少不必要的 GPU 开销。
- **Sequencer 交互优化**：减少拖拽期间的冗余鼠标事件处理，提升拖拽响应性能和流畅度。

## 🐛 Bug 修复

- **渲染修复**：修复 Path Tracer 缺失 specular profile；修复虚拟纹理 DDC 缓存文件写入失败后继续使用损坏数据的问题；修复 D3D12RHI enhanced barrier layout selection 与同步错误；修复 MaterialShader 中因 conservative 和 compilation shader 参数不匹配导致的 assert；修复 VulkanRHI 在带 mips 的 GPU readback 上的 false-positive ensure；调整 SMAA 全屏顶点着色器参数顺序以匹配立体声输出结构体；修复 DOF 在高模糊区域同时包含前景与背景像素时错误选择更高 mip 导致颜色混合的问题。
- **Sequencer 修复**：修复 GetTypeHash 查找错误；在拖拽期间推迟通道重建，避免首次编辑加载后拖拽失败；修复选择多个绑定时详情面板重复显示单个绑定详情；保持键选择在撤销和通道模型重建后可用；修复音频输出在无音频序列时导致的渲染崩溃。
- **Control Rig 修复**：修复切换 spawned control 类型时崩溃；撤销操作不再清除关卡编辑器中的 control 选择；rig 重编译后更新 sequencer channels；连接树视图不再选择禁用元素或意外进入重命名模式；从 legacy 类型创建 Control Rig Asset 时保留变量并正确处理歧义名称；修复多个与模块复制、control shape actor 重建相关的稳定性问题。
- **UAF 修复**：修复 struct binding 中常量值自定义不转发；并行模块 tick 解析相同变量引用时的崩溃；变量引用验证在 asset 自身序列化期间跳过；蒙太奇 slot data 查询通过 scoped update context 路由；恢复注入图的 host-chain container sharing；修复 VariableReferencePropertyCustomization 在无效 Property Utilities 上下文中的崩溃。
- **AIE 修复**：修复 RandomizeColumn 在使用随机流时选择错误索引；修复 Curve Editor 在 flatten keys 命令中未跟踪最后选中 key 的问题。
- **其他工具修复**：修复 PCG Get Graph Parameter 输出引脚类型变化后更新失败、依赖刷新损坏；修复 Horde 提取 artifact/workspace 内容时的路径遍历漏洞；修复 Chooser RandomizeColumn 使用随机流时错误索引；修复 Chaos Vehicles 在 Physics Prediction 开启且由 AIController 驱动时无输入；修复 PhAT 选择系统 nullptr 检查失败和 PhysicsAssetEditor Edit Mode 过度检查；修复 Mac 嵌套窗口移动通知耗尽栈；修复 NDIMedia 动态纹理标志崩溃；修复 shader 预处理取消竞态和未闭合字符串/字符字面量扫描越界；修复 USD primvar baking 属性传播；修复 PoseSearch `FindReferenceOrientation` ensure 触发；修复 MeshSelectionTool 笔画期间热键崩溃；修复 Landscape 旧资产加载时半随机崩溃；修复 MovieRenderPipeline 无音频序列渲染崩溃；修复 cooking 中 ProxyTable 和 RigVM 函数库的确定性问题。

## 🔧 API 变更

- **CoreUObject**：新增 `FFieldPath::IsResolved()` 方法，便于判断字段路径是否已解析。
- **UAF Runtime**：为 transition nodes 添加 source/target accessors，新增 overlay modifier base class，并将 Transitions 暴露给 Blueprint，扩展动画节点创作和蓝图交互能力。
- **Proxy Assets**：修复 output structs 以支持绑定 UAF output variables，使代理资产能够正确输出结构化数据。
- **RigVM**：资产现在 nativizes 其自身拥有的函数；RigVM 函数库在 cook 期间编译到编译器自有存储，提高 cook 确定性。
