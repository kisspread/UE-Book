# 2026-07-20 引擎周报

## ✨ 新功能

- **合成系统：自动激活媒体源**  
  为所有纹理选择器自动激活对应的媒体配置文件源，简化了合成环节中媒体源的接入流程。

- **合成编辑器：通道选择持久化**  
  `SCompositeEditorPanel` / `SCompositePassTree` 现在会记住每个图层的通道选择状态，提升多通道合成场景下的工作流连续性。

- **合成系统：2D 变换通道与视口操作工具**  
  新增 2D 变换通道，并提供视口中的交互式小工具，支持裁剪、柔化、缩放、旋转、翻转操作，可结合 Pilot+G 快捷键进行门控，方便直接在视图中调整合成元素。

- **UAF 大纲视图：增加查看按钮**  
  在变量大纲和函数大纲中加入了视图按钮，方便快速定位和访问相关属性与函数。

- **UAF：变量类型选择器过滤**  
  变量类型选择器现在只显示 RigVM 所支持的类型，避免在创建节点时误选无效类型。

- **动态风：改善低风速表现**  
  减少了极低风速下的振动现象，并为全局风添加了更多变化，使植被等受风物体的动画更加自然。

- **蒙皮场景扩展：新增 Provider Phase 控制**  
  为蒙皮场景扩展引入了 Provider Phase 概念，开发者可以指定蒙皮计算的执行阶段。这允许动态风在渲染阶段运行蒙皮更新，同时使常规蒙皮保持在场景更新阶段，以满足头发蒙皮缓存对早期骨骼变换的依赖。该架构变更使动态风与头发系统能够更灵活地协同工作。

## ⚡ 性能优化

- **动态风：主批量动画剔除**  
  添加了对主批量动画的剔除支持，减少不可见或无关动画的计算开销。

- **Lumen 辐照场收集：探针插值优化**  
  优化了辐照场探针值的插值计算，在 900p 分辨率下为一台主机带来了约 0.17ms 的性能提升（从 0.93ms 降至 0.76ms）。

## 🐛 Bug 修复

- **IOStore 打包修复**  
  修复在启用 IOStore 的情况下，`-createchunkinstall` 过程错误地将非 chunk-0 的 `.utoc`、`.ucas`、`.sig` 和 `.uondemandtoc` 文件排除出最终安装包的问题，确保安装包完整性。

- **Mac 光标图像损坏**  
  修复因步幅计算错误及 `FColor` RGBA 到 ARGB 的通道混合不当而导致的 `FMacCursor::CreateCursorFromRGBABuffer` 生成图像破损的问题。

- **稳定 PSO 缓存序列化未对齐读取**  
  修复由于 `FShaderHash` 从 SHA1 迁移到 XXH64 后，稳定 PSO 缓存序列化中出现未对齐读取的 Bug。

- **合成：渲染目标提取通道冻结**  
  修复当存在活动场景捕获（例如阴影反射捕获）时，渲染目标提取通道会永久冻结的问题。

- **Linux 插件构建链接错误**  
  修复针对已安装引擎构建插件时，缺少 ImportLib 存根 `.so` 文件而导致的链接失败。

- **Lumen 辐照场收集：探针样本偏移计算错误**  
  修正了辐照场探针样本位置偏移的数值计算问题，避免不正确的光照数据。

- **合成/媒体配置文件：未初始化成员**  
  修复了 `SLATE_ARGUMENT` 标量成员未默认初始化的潜在问题。

- **FPaths::IsStaged() 逻辑恢复**  
  恢复了 `RequiresCookedData()` 判断子句，解决了先前清理引入的逻辑回归。

- **UbaJobProcessor 不完整集成**  
  解决了之前变更中 `UbaJobProcessor.cpp` 被部分合并而缺少依赖更改的问题，避免相关功能异常。
