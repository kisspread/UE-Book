# 2026-06-19 引擎周报

## ✨ 新功能
- **Chaos Cloth**: 为 Chaos Cloth 组件添加了光线追踪（Ray Tracing）支持。
- **硬件光线追踪 (HWRT/RHI)**：在 D3D12 RHI 中实现了 Opacity Micromap 支持。
- **程序化内容生成 (PCG)**：在 Scene 工具集中添加了 Data Layer 支持，增强了场景管理的灵活性。

## 🚀 重大变更
- **静态网格 (StaticMesh)**：改进了 MeshDescription 的 Derived Data Cache (DDC) 记录，使其内容具有确定性，并采用了纯构建流水线，提升了构建的可靠性和可缓存性。

## ⚡ 性能优化
- **Nanite 渲染**：移除了 Ray Tracing 回读缓冲区就绪时不必要的断言，并在 `FNaniteRasterPipelines::Unregister` 中增加了防御性代码，增强了稳定性。

## 🐛 Bug 修复
- **编辑器与工具稳定性**：修复了多个导致编辑器崩溃的问题，包括：将不可重设父级的组件提升为场景根组件时、在 Sequencer 中分割动画蒙版区段时、以及加载定义面料的 USD 模拟网格时。
- **Sequencer 与动画**：修复了在绘制骨骼时更改 LOD 级别导致的崩溃；修复了动画混合器中在未设置根运动选项时错误提取根运动的问题；并修复了多个视图交互相关的回归问题。
- **Chaos 物理与布料**：修复了在运行时重新加载 Chaos Cloth 资产时可能出现的崩溃；将骨架根骨骼的缩放正确应用到了模拟碰撞体上。
- **渲染与 GPU**：修复了重复使用 “Build HLODs For selected Region(s)” 选项后可能导致的 GPU 崩溃；修复了当 GI Quality = Medium， Reflection Quality = High 且 Substrate = Adaptive GBuffer 时出现的视觉错误；修复了移动端静态光照下带表面光照的半透明图元缺失级联阴影贴图 (CSM) 的问题。
- **平台与部署**：修复了 Mac 平台上因过期的 `Versions.xcconfig` 文件导致 Finalize 流程失败的问题；修复了 Linux Wayland 平台下通知窗口的定位错误。
- **编辑器 UI 与工作流**：修复了 Slate MultiBox 中因控件委托生命周期管理不善导致的顶层崩溃；修复了状态栏工具栏扩展错误地烘焙共享控件实例的问题；修复了 “DuplicateAssetWithDialog” 忽略调用者提供的包路径的问题。
- **数据流与 PCG**：修复了选择按图元节点在输出面选择类型时工作不正常的问题；修复了权重贴图绘制意外清除其他组件数据的问题；修复了在编辑器中进入 PIE 时，因重建引用了河流修改器的已编译分区导致的崩溃。
- **平台特定修复**：修复了 Windows 平台某些网页或页面切换后 IME（输入法）失效的问题；修复了 Linux 平台下网页与应用间复制粘贴失效的问题。
- **其他领域修复**：修复了在支持与不支持 Strands 几何体的平台预览之间切换时的崩溃；修复了 Slate 后处理着色器使用了错误签名的问题。

## 🔧 API 变更
- **AI 助手工具集**：更新了 `UAIAssistantToolset::GetDockedContext` 以适配新的基于面板的抽屉布局。
- **Composure**：允许用户在 Composure 面板上选择在编辑器中被隐藏的 Actor。
- **新辅助函数**：添加了 `MemStack::AllocateArrayView(...)` 帮助函数，简化内存分配。
