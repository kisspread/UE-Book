# 2026-07-16 引擎周报

## ✨ 新功能
- **Dynamic Wind**: 新增对 Cardinal Batched Animations 的裁剪功能，提升渲染性能。

## ⚡ 性能优化
- **Lumen 辐照场采集**: 优化探针插值性能，在主机 900p 分辨率下耗时从 0.93ms 降低至 0.76ms，节省 0.17ms。

## 🐛 Bug 修复
- **Dynamic Wind**: 修复低速风时叶片振动过强的问题，并增加全局风的随机变化，使表现更自然。
- **复合材料（Composite）**: 修复场景捕获（如 ShadowReflection）激活时，Render Target Extraction Pass 冻结的问题。
- **Linux 平台**: 修复在已安装引擎版本中构建插件时，因缺少 ImportLib stub .so 导致链接失败的问题。
- **Lumen 辐照场采集**: 修复探针样本位置偏移量的计算错误，该错误可能影响插值质量。
- **路径工具**: 恢复 `FPaths::IsStaged()` 中 `RequiresCookedData()` 子句，修正之前部分集成引入的逻辑缺失。
- **合成/媒体配置文件**: 修复未初始化的标量 `SLATE_ARGUMENT` 成员，避免潜在的未定义行为。

## 🔧 API 变更
- **蒙皮场景扩展（Skinning Scene Extension）**: 新增 Provider Phases，用于控制蒙皮计算在渲染管线中的执行时机。该项变更允许 Dynamic Wind 在渲染阶段执行蒙皮，而常规路径仍在场景更新阶段执行以满足依赖需求；毛发皮肤缓存系统依赖早期管线中的骨骼变换，通过 Phases 机制可正确协调执行顺序。
