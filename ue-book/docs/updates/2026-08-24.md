# 2026-08-24 引擎周报

## ✨ 新功能

- **UAF Layering**：为基于动画节点的层级堆栈添加工作区预览支持，使开发者可以在工作区直接预览层级配置效果。
- **Control Rig Rig Promises**：引入 Rig Promises，在 Rig 构建之前提供关于该 Rig 将构造内容的契约，调用方无需等待 Rig 完全构建即可获取关键信息。
- **UAF Entity Movement Trajectory**：为 Verse 场景图实体添加实体运动轨迹生成能力，用于支持基于运动轨迹的动画和游戏逻辑。
- **Direct Mesh Control**：
  - 支持从子组件（拥有或附加）提取 DMC 数据，扩展了数据来源范围。
  - 报告影响 DMC 形状生成的骨骼网格简化设置，帮助开发者理解形状生成依据。
- **Group Paint Tool**：添加隔离选择和对称绘制能力，提升群组绘制工具的灵活性和效率。
- **Anim Mixer**：为 Anim Mixer 添加 FBX 导出和 Map Skeletal Motion to Root 功能，使其与动画编辑器功能对齐。
- **Xbox Live / GDK**：添加 2017 模式成就进度百分比支持，并支持获取 2017 模式的排行榜，同时设置正确的排行榜模式。
- **UnrealTraceServer**：发布 1.25 版本，包含内部改进和修复。
- **UAF Editor**：使属性包支持的变量默认值编辑可事务化，支持 Undo/Redo 操作。
- **AIE Time Posing**：重新设计激活种子逻辑，在 FTimePosingSequencerExtension::SetActive 中统一解析种子，消除与曲线编辑器适配器的竞争条件，并改进居中行为。

## ⚡ 性能优化

- **UAF**：将属性模式和类型化集合容器合并为单个分配，减少内存分配次数和内存碎片。
- **FInpaintSolver**：预计算 inpaint 能量矩阵，在多个属性传递之间重用，避免重复计算，加速属性传递过程。
- **Direct Mesh Control**：
  - 如果网格未被渲染，则不更新网格对象或排队变形器工作，避免每帧不必要开销。
  - 生成 DMC skms 时移除无用属性，减少内存占用和潜在处理开销。
- **Gizmo**：修复动画模式在不需要时绘制 Gizmo 的问题，减少额外绘制调用。

## 🔧 API 变更

- **LevelSequenceEditor**：新增 `RestorePreAnimatedState` 和原生 `GetCurrentSequencer` 方法，方便脚本和扩展调用。
- **Sequencer**：通过 `UMovieSceneSequenceExtensions` 将 `IsPlayableDirectly` / `SetPlayableDirectly` 暴露给蓝图和 Python。
- **RigVM**：进行小型 API 修复，提升 AI 友好性。
- **Sequencer**：规范化绑定上下文标识符，使其成为干净一致的令牌（无前导 F、无空格），并提供人类可读的显示名称。
- **UAF**：将 `FAttributeNamedSet` / `FAttributeTypedSet` 重命名为 `FNamedSetSchema` / `FTypedSetSchema`，并更新相关文件。
- **SStructureDetailsView**：支持 `bShowHeaders`，使结构细节视图可以隐藏分类头，与 `SDetailsView` 行为一致。
