# 2025年8月引擎更新月报

8 月是 **Iris 复制系统从 Experimental 升格为正式版**、**Lumen HWRT 也可在分屏中使用** 的一个月，主题是围绕网络同步与多视图的“整合”。

在渲染方面，**Nanite 第一人称视角（First-Person）支持**、**Substrate 折射模型重新设计**、**Chaos Physics 任务化带来最多 25% 吞吐量提升** 等均取得进展。

工具方面也集中进行了伴随迁移的整理：**PCG Editor Mode (Beta)**、**Media Viewer / Motion Design Scene State / Data Link 升格为 Beta**、**Verse 编译器／VM 提速约 15〜20%**、**旧版性能分析器与内存分析器被完全移除** 等。

## ✨ 新功能

**Nanite 支持第一人称视角（First-Person）渲染**

> 现在可以使用 Nanite 绘制高细节的第一人称角色与武器，并可通过材质的可编程插值（programmable interpolation）在世界空间与第一人称空间之间进行插值。这是面向 FPS 的 Nanite 工作流的基础。
>
> _来源: [2025-08-27](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/37)_

**Lumen 硬件光线追踪支持分屏**

> 此前仅限于单一视图的 Lumen HWRT 现已支持多视图，在本地多人分屏游戏中可以使用高质量 GI。其基础包括 `FRayTracingScene` 本身的多视图化以及 `FRayTracingInstanceCollector` 的重构。
>
> _来源: [2025-08-25](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/35) / [2025-08-26](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/36) / [2025-08-27](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/37)_

**PCG Editor Mode 进入 Beta**

> 引入了一种新的编辑器模式，可以在视口中通过绘制样条线、绘制、生成体积等工具操作直接创建 PCG 内容。本月内还持续加强了 PCG 相关功能，包括多边形与属性操作节点的扩展、Polygon2D 元数据支持、`@Data.$NumElements`、多边形裁剪、Biome Core 对骨骼网格体植被的支持等。
>
> _来源: [2025-08-12](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/22) / [2025-08-14](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/24) / [2025-08-19](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/29) / [2025-08-20](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/30) / [2025-08-22](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/32)_

**Chaos Cloth: 支持 Outfit 资产与 Reference Bone**

> 支持一种新的 Cloth/Outfit 资产格式，可以在单个 `SkeletalMeshComponent` 上运行多个布料模拟。还添加了在布料资产中指定 `Reference Bone` 的功能，使得复杂的服装设置成为可能。
>
> _来源: [2025-08-20](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/30)_

**Nanite 网格体支持 `bOwnerNoSee` / `bOnlyOwnerSee`**

> 实现了此前 Nanite 网格体无法使用的基于所有者的可见性控制（仅所有者可见／所有者不可见）。这是将 Nanite 与第一人称视角结合时必不可少的控制，例如 FPS 中仅自己可见的武器网格体。
>
> _来源: [2025-08-20](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/30)_

**Heterogeneous Volume 支持直接光的级联阴影贴图**

> 体积度量渲染现在可以使用 CSM（级联阴影贴图），提高了室外大气、雾、烟的质量。
>
> _来源: [2025-08-06](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/17)_

**Substrate Format=1 支持 Lumen ShortGI**

> 注重性能的 GI 表现现已在 Substrate 格式 1 中可用，使得在轻量级场景中采用 Substrate 更加容易。

## ⚡ 性能优化

**Chaos Physics: 基于任务的更新带来最多 25% 吞吐量提升**

> 引入并行执行积分、运动学更新、宽阶段更新的任务图，在物理对象较多的场景中观测到最多约 25% 的性能提升。
>
> _来源: [2025-08-14](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/24) / [2025-08-21](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/31)_

**Verse 编译器提速约 20%，Verse VM 提速约 15%，LSP 也缩短数百毫秒**

> 通过 `LogicalScope` 内使用 `CSymbol->Definitions` 映射加速定义查找，构建时间减少了约 20%。通过减轻 Verse VM 失败上下文处理的负担，无副作用情况下运行速度提升约 15%。Verse LSP 通过 VST 克隆方式的差异分析，解析时间缩短了数百毫秒。还加入了如 `@available` 版本计算缓存等额外优化。
>
> _来源: [2025-08-11](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/21) / [2025-08-18](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/28) / [2025-08-19](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/29) / [2025-08-26](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/36)_

**Lumen“高”预设约减轻 0.5ms，VSM 默认值更贴近 60Hz**

> 在 Lumen 的“高”可伸缩性下，`r.Lumen.ScreenProbeGather.StochasticInterpolation 2`（半分辨率集成）已改为默认值，在主机 1080p 下可节省约 0.5ms 的 GPU 时间。此外，局部光源 VSM 的 `r.Shadow.Virtual.MarkCoarsePagesLocal` 默认值改为 2，方向光 VSM 的接收器掩码也默认启用，从而整体改善了面向 60Hz 目标的性能。
>
> _来源: [2025-08-22](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/32) / [2025-08-28](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/38)_

## 🔧 API 变更

**Sequencer 的绑定解析 API 支持返回多个对象**

> `FMovieSceneBindingResolveResult` 现在可以返回对象数组而非单一对象，`GetSingleBoundObject` 已被弃用。今后请使用 `GetBoundObjects`。
>
> _来源: [2025-08-13](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/23) / [2025-08-29](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/39)_

**将 `UMaterialInterface::GetUsedTextures` API 重构为基于 `TOptional`**

> 从旧的枚举 + 布尔值对签名改为基于 `TOptional`，提高了 API 的可读性。获取材质使用的纹理时，调用方需要进行相应更新。
>
> _来源: [2025-08-21](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/31)_

**`RHICreateTextureReference` / `RHIUpdateTextureReference` 已弃用**

> 调用方需要迁移为显式传递命令列表的形式。作为临时应对添加了 `RHIClearTextureReference`。纹理创建也已大规模迁移到基于 `RHICmdList.CreateTexture` 的新 API。
>
> _来源: [2025-08-25](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/35) / [2025-08-29](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/39)_

**Iris: 删除 `SetConnectionFilter` API**

> 连接级别的过滤已由排除组（Exclusion Group）取代。现有的 `UReplicationSystem::SetConnectionFilter` 调用需要进行迁移。
>
> _来源: [2025-08-29](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/39)_

**UAF (AnimNext): 公开模块变量读写辅助函数**

> `UE::UAF::SetModuleVariable` / `WriteModuleVariable` 已公开，现在可以从 Mass、StateTree 等外部框架直接读写 UAF Animation Module 变量。
>
> _来源: [2025-08-22](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/32)_

**Verse 默认初始化器中允许 `<reads>` 效果**

> 现在可以在 CDO 初始化时使用浮点常量等特定 `<reads>` 效果。
>
> _来源: [2025-08-25](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/35)_

## 📌 重点关注模块

**Iris / Networking**：从 Experimental 毕业 → 正式版＋始终启用、事务性 RPC 重调度、RPC 状态损坏检测、`SetConnectionFilter` 废弃等，面向生产部署的整理工作一气呵成地推进。

**PCG**：以 Editor Mode (Beta) 的引入为中心，Polygon2D 元数据／属性操作节点／Biome Core 骨骼网格体植被／FastGeo 联动插件等，程序化生成的工作流在多个方面得到扩展。
