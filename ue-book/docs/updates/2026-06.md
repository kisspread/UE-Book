# 2026年6月引擎更新月报

## ✨ 新功能

- **构建、缓存与工具链**：`SubmitTool` 支持启动时自动拉取并合并代码库配置；新增 `QueryParams` 预检 URL 参数配置；构建管线工具（BPT）开放加密状态查询，支持 `-ListBinaries`、UploadBinary dry-run、热修复上传与 UI 校验；构建管线服务（BPS）改进 CDN 截断与 Chunk 上传处理；DDC 回放行为可配置并合并到层级结构；新增 `MemStack::AllocateArrayView(...)`；添加 mimalloc v3.3.2。
- **编辑器与工作流**：`Details` 面板 Actor 标题新增“浏览到蓝图”；`ModelessTools`、`InteractiveVisualizers` 模块初步集成 `FEditorModeTools`；新增 `CheatsToolset`；`EditorAppToolset` 增加通知、缩略图缓存、视口显示标志、视图模式与编辑器模式操作；`BlueprintTools` 支持蓝图变量 tooltip get/set、`disconnect_pins`、非脏查询与函数标志；`AssetTools` 新增 `reload_asset`，`read_file`/`write_file` 改为作用于 Unreal 虚拟内容路径；`StateTree` 层级图新增逐过渡引脚。
- **AI/MCP/Unreal Toolbox**：`MCPClientToolset` 支持本地 MCP 服务器 stdio 传输；`FToolsetImage` 可通过 schema `title` 提取为 MCP 内容块；`UnrealConsole` 增加 `-mcp` 模式并集成引擎工具集；Unreal Toolbox 支持工具图标、遥测 schema/基础架构、预发布更新通道与市场源并发轮询；`UMG` In-World Widgets 增加深度与速度输出选项。
- **渲染与图形**：Gaussian Splat 管道迁移到 GPU 驱动模式，`UGaussianSplatComponent` 新增 `PointScaleFactor`、`OpacityScale`，并支持深度与速度写入；Nanite Groom 构建器支持曲线蒙皮数据生成；Chaos Cloth Component 增加光线追踪支持；D3D12 RHI 增加 Opacity Micromap 支持；Lumen 新增 `r.Lumen.SkylightPrefilterMipBias`，新增基于裁剪球体的 Mesh Card 剔除与分辨率计算选项；默认在 Valve Frame Lepton 设备启用 PSO 预缓存；`PrimitiveComponent` 新增 `bWantsSelectionOutline`。
- **动画、角色与 MetaHuman**：AIE 新增 Easy Ease、Blend to Trajectory、Blend to Noise、Blend to Wave、Blend To Buffer、Bale To Interval 等工具；Control Rig Asset Factory 支持 Control Rig 动画节点描述；RigVM 事件节点支持可变输出引脚；UAF 新增可选择的 Source/Base 角色、编译时 bindable-value 校验、bindable-value 属性遍历、跨 VM 事件调度与编辑器 UDS/UDE 支持；Chaos 支持可变形逆向肌肉激活及调试绘制；支持从 DNA 生成平滑骨骼网格体，拖放 DNA 到内容浏览器时提供 UEMHC 兼容导入选项。
- **PCG/Dataflow**：PCG 新增二维凹包查找算法、追踪管理器对象替换、图设置 `PartitioningCookScope`、运行时调度器数据层/EDL 支持；Dataflow 新增 `FindMeshSymmetryPlane` 节点及近似平面对称性检测器；Dataflow Transfer 为顶点属性公开修复/ inpainting 功能；Dataflow 实现 PreviewBP。
- **平台、输入与媒体**：Android 新增双向远程控制台并复用 Win64 实现；Android 通过 Google Play Review API 支持应用内商店评测；可通过 `input.UseInputThread` 启用专用输入线程轮询 `IInputDevices`；应用 `IInputDevice` 注册与创建整合到 `GenericApplication`；Linux 使用 SDL3 后端的 `AudioCaptureCore`；Wasapi 启用 Windows Audio Processing Objects；Rivermax SDK 部分升级至 1.90.18；Composure 新增 Render Target Extraction 手动提取 Pass；SCC 新增依赖验证软引用支持 `EnableValidatingSoftDependencies`。
- **网络与资产**：`PrimaryAssetTypeInfo` 新增 `bNeedsLoadForCooking`；`DataLayerInstance` 新增可通过 CVar 在运行时覆盖 `InitialRuntimeState` 的属性；`SubsystemCollection` 允许在 `UEngineSubsystem` 上进行跨集合 `InitializeDependency`；`UNetDriver` 新增 `OnConnectionRemoteAddrUpdated` 委托；新节点创建系统管理 `NodeDesc` 生命周期并用于 `ChooserPlayer`；Motion Design 引入 ClonerEffector。

## 🚀 重大变更

- **StaticMesh 构建与 DDC**：StaticMesh 引入纯构建流水线与内容寻址的源 `MeshDescription` DDC 记录，并确保 DDC 记录内容确定性。
- **渲染与 RHI**：MegaLights 多个着色器在 `ThreadGroupSizeMode 1` 下线程组调整为 16x8；`ScreenSpaceRayTraceLightSamplesCS` 增加无跟踪压缩屏幕追踪选项；Lumen `r.Lumen.IrradianceFieldGather.NumClipmaps` 调整为 6；`D3D12_RAYTRACING_PIPELINE_CONFIG` 改为 `D3D12_RAYTRACING_PIPELINE_CONFIG1`；桌面 VulkanRHI 资源删除延迟改为 0，并通过 `RHIProcessDeleteQueue` 处理 `DeferredDeletionQueue`；移除已废弃多视口支持与 Oculus 着色器；移除 `r.RayTracing.EnableOnDemand`，相关功能默认可用；TSR 对 Nvidia 驱动版本高于 610.00 的显卡默认启用 16 位 VALU。
- **保存、线程与对象系统**：`SavePackage` 默认错误处理器由 `GError` 改为 `GWarn`，避免 Cook/过程化保存崩溃；`UObject::LoadConfig` 避免绕过 `FConfigCacheIni` 线程安全；`ULandscapeHeightfieldCollisionComponent` 改用事务安全读写锁；原型预填充通过 CVar 禁用，以避免复杂对象图重实例化问题；`LaunchMultiServer` 不再支持 `-client=` 中多个相同客户端条目；`FPlatformTLS` 撤销最大线程数提升上限。
- **算法与配置**：`Algo::ParallelDeterministicSort` 重构为跨不同 worker 数量确定性排序；`BuildSettings` 增加 `BuildSettingsVersion` 辅助；`UE_DEPRECATED` 目标版本由 `6.0` 修正为 `5.9`；`bNeedsLoadForCooking`、DDC 回放配置、UAT/Gauntlet 命令行参数最后一个值覆盖先前值；CommonUI 编辑器按键传递改为从 `CommonUISettings` 读取忽略绑定列表，默认保留旧版“停止播放会话”忽略设置；PC GDK 插件移出 Beta；Bink 视频库更新至 2026.06；MetaSound Controller API 启动向 Builder API 迁移第一阶段。

## ⚡ 性能优化

- **MegaLights/Lumen**：`ScreenSpaceRayTraceLightSamplesCS` 在 `ThreadGroupSizeMode 1` 下使用 128 线程，特定主机 540p 可节省约 0.12 ms；Lumen Irradiance Field Gather 合并深度/法线降采样与标记 pass 并统一像素偏移，900p 总体成本约维持 0.3 ms；Lumen Mesh Card 排序保证稳定顺序，降低非确定性 Cook 风险。
- **着色器与渲染**：SPIRV-Tools `RedundancyEliminationPass` 预分配向量大小，`FTSRRejectShadingCS/121` 等编译时间约减半；GPU Radix Sort 支持间接派发；Nanite RT 使用 `RootPageIndex` 替代 `RuntimeResourceID`；骨骼网格体可在阴影深度渲染中按静态网格体渲染，约 1.4 万面网格阴影深度从 0.16 ms 降至 0.08 ms；VulkanRHI 窗口销毁增加显式同步、缓冲区回读增加缺失屏障；`MediaTexture` 修复游戏构建性能回退；BloomUpA 采样精度从 half 改 float。
- **编辑器与 UI**：TEDS Outliner 合并新增行后单次排序更新；Prefab 编辑器大纲启用 Slate 动态失效；内容浏览器源树包裹在单次失效操作中；长可编辑文本 `GetText` 增加缓存；ToolsetRegistry 执行工具时抑制编辑器 CPU 节流；`MaterialInterface` 非必要不创建 RWLock。
- **系统与模块**：`MapCaseInsensitiveFile` 提升重复查询目录性能；`UMassReplicationSubsystem::SynchronizeClientViewers` 无 replication bubble 时提前返回；Mass 导航更新管线增加节流；`MassCharacters` CVar 增加 Scalability 标志；GFP 引擎初始化避免复制 `GfpInfoMap`；音频平台设置在任务线程首次访问前预加载；Wasapi 缩小 `DeviceSwapCriticalSection` 作用范围；EpicWebHelper 构建时禁用未使用 ICU 与 EditorOnlyData；Mutable 改进移动平台图像纹理参数质量与性能，并消除几何体重导入导致的重复 Section 开销；Chaos Cloth 缓存 `p.ClothPhysics.UseEndTickWait` CVar 指针。

## ⚠️ 废弃预告

- UMG `Touch Action Wrapper` 添加废弃消息。
- 材质编辑器隐藏已废弃的 “Enable Exec Wire” 选项，计划在 5.8 完全移除。
- `LazyObjectPtr` 进入废弃/迁移流程，并提供 Commandlet 解析项目数据生成 GUID 到软对象路径映射，可通过 ini 在加载时转换。
- `UE_DEPRECATED` 目标版本由 `6.0` 修正为 `5.9`；`Swap` 对 `const` 值调用将产生警告；`OnPackageLoadComplete` 回调标记废弃。
- 移除 `StateHandle` 生命周期管理 CVar；移除视图中的多视口与 Oculus 着色器；移除 `r.RayTracing.EnableOnDemand`；Landscape Layer Blend 旧行为需通过 `landscape.UseLegacyLayerBlendMaterialExpressionBehavior` CVar 启用（需重启）。
- `GameInput` 部分包含防护类型由 `windows` 改为 `Microsoft`，以支持 NuGet 版本在 Windows 之外编译。
