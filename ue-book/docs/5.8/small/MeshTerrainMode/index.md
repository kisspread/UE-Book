## 用途

Mesh Terrain Mode 是 UE5 中的一个**实验性编辑器模式**，专门用于创建和编辑 Mesh Partition（网格分区）。它提供了一整套交互式工具，用于在编辑器中构建和操控基于网格的地形系统。

与标准的 Modeling Mode 类似，但 Mesh Terrain Mode 专注于**网格分区/地形工作流**，包含：

- **MegaMesh 工具链**：专为大面积地形网格设计的转换、拆分、合并、缝合、重划分等工具
- **高度图编辑**：支持导入高度图、高度雕刻、平滑、平坦化、坡度侵蚀等画笔工具
- **修改器系统**：支持重网格、补丁、投影、样条、噪声、布尔、晶格等修改器叠加
- **完整建模工具集**：包含基本图元、雕刻、多边形编辑、UV、材质、碰撞、LOD 等全套工具
- **网格元素选择系统**：支持三角形、顶点、边、分组面的选择与变换
- **资产自动生成与管理**：可配置自动生成静态网格体资产的路径、命名、保存策略
- **子模式系统**：将工具组织为形状、创建、编辑、雕刻、烘焙、绘制、修改器等子模式

简而言之，这是**专门面向网格地形创作的编辑器模式**，将建模工具与地形/分区特定功能（MegaMesh、高度图、修改器）集成在一起。

## 使用场景

- 你需要创建大面积的网格化地形并进行雕刻编辑 → 使用 Mesh Terrain Mode
- 你需要通过高度图导入来快速生成地形网格 → 使用 Mesh Terrain Mode 的 Heightmap Import 工具
- 你需要对地形网格进行叠加修改（重网格、补丁、样条、噪声等）→ 使用修改器系统
- 你需要将多个地形网格段合并、缝合或重新分区 → 使用 MegaMesh 工具集
- 你需要对地形进行多层级细节编辑（雕刻、材质、碰撞）→ 使用相应的子模式

## 蓝图用法

该插件主要作为**编辑器模式**使用，核心交互通过编辑器 UI 完成，不暴露典型的蓝图可调用函数。以下是与编辑器模式交互的方式：

### 核心编辑器模式切换

| 节点 | 说明 | 所在类 |
|---|---|---|
| `EM_MeshTerrainEditorModeId` | 编辑器模式 ID 常量，用于激活模式 | `UMeshTerrainMode` |

### 设置类

| 设置类 | 说明 |
|---|---|
| `UMeshTerrainModeSettings` | 项目级设置：资产生成路径、保存策略、默认网格对象类型等 |
| `UMeshTerrainModeCustomizationSettings` | 编辑器级设置：UI 自定义、选择颜色、工具面板尺寸、画笔 Alpha 集等 |

### 主要子模式

| 子模式 | 说明 |
|---|---|
| Shapes | 基本形状图元创建 |
| Create | 多边形绘制、路径绘制、样条等创建工具 |
| Edit | 多边形编辑、变换、对齐、合并等操作 |
| Sculpt | 网格雕刻（包括高度雕刻画笔） |
| Bake | 烘焙属性贴图、顶点属性 |
| Paint | 材质绘制、属性绘制 |
| Modifiers | 地形修改器叠加（重网格、补丁、样条、噪声、布尔等） |

### 使用示例（蓝图描述）

由于 Mesh Terrain Mode 是编辑器模式，使用方式为：

1. 在编辑器中点击视口工具栏中的 **Mesh Terrain** 按钮进入模式
2. 通过左侧子模式面板选择目标子模式（如 Sculpt、Modifiers 等）
3. 从工具面板选择具体工具开始编辑
4. 使用快捷键 Accept/Cancel 完成或取消工具操作

## C++ 用法

### 头文件引入

```cpp
#include "MeshTerrainMode.h"
#include "MeshTerrainModeSettings.h"
```

### 基本用法 — 访问编辑器模式设置

```cpp
// 获取 Mesh Terrain Mode 的项目设置
UMeshTerrainModeSettings* Settings = GetMutableDefault<UMeshTerrainModeSettings>();

// 配置资产生成位置
Settings->SetAssetGenerationLocation(EMeshTerrainModeAssetGenerationLocation::AutoGeneratedWorldRelativeAssetPath);

// 配置资产生成行为（自动保存 vs 提示）
Settings->SetAssetGenerationMode(EMeshTerrainModeAssetGenerationBehavior::AutoGenerateAndAutosave);

// 配置默认网格对象类型
Settings->DefaultMeshObjectType = EMeshTerrainModeDefaultMeshObjectType::StaticMeshAsset;

// 启用网格选择系统
Settings->SetMeshSelectionsEnabled(true);
```

*来源：Source/MeshTerrainMode/Private/MeshTerrainModeSettings.h*

### 基本用法 — 注册编辑器模式工具扩展

```cpp
// 通过 IMeshTerrainModeToolExtension 模块化接口为 Mesh Terrain Mode 添加自定义工具
class FMyTerrainToolExtension : public IMeshTerrainModeToolExtension
{
public:
    virtual void GetExtensionSubmodes(TArray<FExtensionSubmodeDescription>& SubmodesOut) override
    {
        FExtensionSubmodeDescription Desc;
        Desc.MakeNewSubmode = []() -> TSharedPtr<UE::MeshTerrain::FSubmode>
        {
            // 返回自定义子模式
            return nullptr;
        };
        SubmodesOut.Add(Desc);
    }

    virtual void GetExtensionCustomTools(const FExtensionToolQueryInfo& QueryInfo, 
        TArray<FExtensionCustomToolDescription>& OutTools) override
    {
        FExtensionCustomToolDescription ToolDesc;
        // 配置工具...
        OutTools.Add(ToolDesc);
    }
};

// 注册扩展（在模块启动时）
FMyTerrainToolExtension* Extension = new FMyTerrainToolExtension();
IModularFeatures::Get().RegisterModularFeature(IMeshTerrainModeToolExtension::GetModularFeatureName(), Extension);
```

*来源：Source/MeshTerrainMode/Private/MeshTerrainModeToolExtensions.h*

## Demo 示例

以下是一个最小示例，展示如何通过 C++ 注册一个自定义工具扩展到 Mesh Terrain Mode：

```cpp
// MyTerrainToolExtension.h
#pragma once

#include "MeshTerrainModeToolExtensions.h"

class FMyTerrainToolExtension : public IMeshTerrainModeToolExtension
{
public:
    FMyTerrainToolExtension();
    virtual ~FMyTerrainToolExtension();

    // IMeshTerrainModeToolExtension 接口
    virtual void GetExtensionSubmodeAddons(TArray<FExtensionSubmodeAddon>& AddonsOut) override;
    virtual void GetExtensionSubmodes(TArray<FExtensionSubmodeDescription>& SubmodesOut) override;
    virtual void GetExtensionCustomTools(const FExtensionToolQueryInfo& QueryInfo, 
        TArray<FExtensionCustomToolDescription>& OutTools) override;

    static FName GetModularFeatureName() { return IMeshTerrainModeToolExtension::GetModularFeatureName(); }
};
```
