# 2026-08-17 引擎周报

## ✨ 新功能

- Animating in Engine：Snapper 标签页新增交换 child / parent 选择的按钮；Anim Tree 编辑器新增图形编辑支持，并通过 `ShowOnNode` 标记在编辑器中暴露动画节点描述属性。
- UAF：新增 Control Rig Labels、Timeline State RigVM 节点、嵌套 layer content provider、layer 颜色指示覆盖、Sound / Niagara Notifies、IsLooping 与 TimeActive StateTree 条件；支持将 UPoseSearchDatabase 拖放到任意 UAF anim node slot 并直接实例化为 Motion Matching 节点；新增 anim node retarget 方法，并将 Input Value 节点重命名为 Use External Pose。
- Dynamic Wind：新增外部速度体积纹理支持；风力资产查看器新增 settling time / frequency ramp 图形与热力图可视化；将频率、flutter、damping ramp 等参数调整为比例以保持资产一致性；裁剪骨骼网格冗余数据。
- PostProcess：支持在 renderer settings 中设置项目级默认 tone curve。
- PVE：新增 PVNaniteAssemblyBuilder、PVMeshBuffer、PVAssetHelpers，并添加 Nanite 导出开关。
- Outliner：将 GUID/name accessors 与 Find References 提升到公共 outliner 基类，Functions outliner 获得与 Variables outliner 一致的查找引用能力。
- Control Rig：新增可生成元素的 unit 分类。
- Lumen：hit-lighting 改进。
- MediaIOFramework：在 Timecode sample evaluation 降级为 Platform Time 时新增警告，并在 CaptureCardMediaSource tooltips 中说明 Just-In-Time Rendering、Sample Evaluation Type 与 Framelock 要求。

## 🚀 重大变更

- UAF variable refactor Phase 1：引入 Input / Internal / Local scopes、input variable context，以及 graph / Blueprint 访问支持。
- UAF Attribute 体系重构：FAttributeBindingData 改为 UObject 类型 UUAFAttributeSchema，减少引用计数开销，并规避 AutoRTFM 问题；同时移除 FAttributeNamedSetPtr 与 FAttributeTypedSetPtr，改用引用。
- PVE Export 流程重构。

## ⚡ 性能优化

- UAF Attribute 绑定数据转为 UObject 后，减少 ref-counting churn。
- Lumen hit-lighting 改进提升光照计算效率与质量。

## 🐛 Bug 修复

- Animating in Engine：修复 Snapper 标签页右键拖拽平移；修复 Selection Sets 选择时 Sequencer Selection filter 残留 Control Rig 控件。
- UAF：修复 Enum Compare 损坏导致无法选择任何 enum；修复 chooser column variable selection 崩溃；修复 value transformers 的一批精度问题。
- Control Rig：修复多实例并发初始化导致的崩溃与堆损坏；修复 Runtime Control Rig 资产不发送 Compiler Results 编译消息；修复源 Control Rig 未加载时 description refresh 问题；修复 control shape setting 更新时颜色与 hover 属性未刷新；修复 Show Bubble 启用且图表缩小时 comment bubbles 缩放错误。
- Movie Render Pipeline：修复多个 MRQ 相关 PIE 生命周期问题，以及 Blueprint 编译失败中止渲染时 Quick Render 崩溃。
- NDIMedia：将 NDI runtime library 加载失败从 Error 降级为 Warning/Log。
- PoseSearch：修复 Database / Schema 竞争导致的 fatal check；处理 GetDatabaseAnimationAsset 返回 null 的情况。
- 通用：修复绑定 const 引用到 FText::ToString() 临时 FString 导致的 use-after-free；修复 ULandscapeComponent 相关 CDO 的非确定性；修复 stereo layer editor preview 纹理方向、正面与旋转缩放问题。

## 🔧 API 变更

- UAF：移除 FAttributeNamedSetPtr / FAttributeTypedSetPtr，改用 FAttributeNamedSet& / FAttributeTypedSet&；FAttributeBindingData 改为 UUAFAttributeSchema UObject。
- UAF：Input Value 节点重命名为 Use External Pose；新增 anim node retarget 方法。
- Anim Tree：动画节点描述属性可通过 `ShowOnNode` 标签暴露给 Anim Tree 编辑器。
- 日志宏迁移：UE_CLOG 迁移到 UE_CLOGF。
- CowRef 简化：ForceMutable 合并入 GetMutable，避免不当使用。
