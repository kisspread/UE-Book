# 2026年8月引擎更新月报

## ✨ 新功能

- **Control Rig 约束系统全面焕新**：动画编辑器模式引入全新约束编辑 UX。支持直接选择与编辑约束、可视化约束（绘制父子点与连线）、弹出菜单不再被屏幕边缘裁剪、面板加入滚动条与快速烘焙按钮，右键菜单中的烘焙入口被移除。约束行按钮布局针对窄面板做了防裁剪处理，并修复动态偏移问题。
- **Control Rig 图表交互强化**：按住 Ctrl 拖动变量到图表创建 Getter 节点，按住 Alt 创建 Setter 节点；蓝图独立的 Control Rig 资产显示完整图表右键上下文菜单；添加变量按钮会自动滚动到新变量并进入编辑模式。
- **Control Rig 模块化流程优化**：模块化 Rig 编辑器的事件队列标签页跟随模块层级选择；模块详情中的数组连接器支持重置、使用选中项与选择元素；新增重新加载按钮，Rig 骨骼网格变化时视图显示刷新按钮。
- **Control Rig Rig Promises**：在 Rig 构建之前提供关于该 Rig 将构造内容的契约，调用方无需等待 Rig 完全构建即可获取关键信息。新增可生成元素的 unit 分类。
- **UAF 绑定与数据流改进**：可绑定值绑定 UI/UX 全面升级，支持 lozenge 样式、拖放与实时验证；变量重命名/替换扩展到所有资产类型的可绑定值绑定；绑定选项从骨架定义移至 UAF 组件并提供对应 API；Montage 组件将惯性化请求查找方法公开为公共 API；新增立即通知系统（Immediate Notify V1）。
- **UAF / Verse 动画集成**：将 UAF 系统暴露给 Verse，使 `skeletal_animations` 能够作为 UAF 系统运行；为 Verse 场景图实体添加实体运动轨迹生成能力。
- **UAF 扭曲与对齐**：`AlignSequence` 节点重命名为 `AlignWarp`，新增缓和的偏斜扭曲对齐，对齐节点 API 更新并增加参考实现；UAF ValueBundle 支持每骨骼重新定向模式，Pose Value Bundle 重定向工具加入 UAF Value 运行时。
- **UAF 内容与编辑器能力**：新增 Control Rig Labels、Timeline State RigVM 节点、嵌套 layer content provider、layer 颜色指示覆盖、Sound / Niagara Notifies、`IsLooping` 与 `TimeActive` StateTree 条件；支持将 `UPoseSearchDatabase` 拖放到任意 UAF anim node slot 直接实例化为 Motion Matching 节点；新增 anim node retarget 方法，`Input Value` 节点重命名为 `Use External Pose`；动画树资产可作为 RigVM 值（如通过 UOL 绑定作为模块变量）；UAF Notifies 暴露 `IsBlendingOut`。
- **UAF Layering**：为基于动画节点的层级堆栈添加工作区预览支持；新增 layer content providers，支持额外的 internal node input。
- **UAF 属性与其它**：属性包支持的变量默认值编辑可事务化（支持 Undo/Redo）；提供 UAF 核心模块开发指南。
- **Dynamic Wind 系统**：新增调试模式可视化实例追踪内存与使用情况；默认资产设置引入沉降时间斜坡；新增质量检查工具、基础网格截面与尺寸推导；分离速度与振幅 CVar 使其以不同速率变化；提供调试可视化、装配体收集与基于曲率的弯曲状态；新增外部速度体积纹理；风力资产查看器新增 settling time / frequency ramp 图形与热力图；频率、flutter、damping ramp 等参数调整为比例以保持资产一致性。
- **PVE**：新增 PVNaniteAssemblyBuilder、PVMeshBuffer、PVAssetHelpers 与 Nanite 导出开关；新增完整网格导入管线，包括 static-mesh importer、PVMeshImport 节点、imported-mesh LOD 节点、MeshBuilder deformed-geometry 路径、graft provenance 与 graft-aware synthesis，以及 diff/diagnostic tooling 与可视化测试；ImportedMesh 到 Mesh pin 连接自动插入 conversion nodes。
- **Direct Mesh Control**：支持从子组件（拥有或附加）提取 DMC 数据；报告影响 DMC 形状生成的骨骼网格简化设置。
- **Sequencer**：扩展 marked frames，新增 EndFrame 与创建 mark ranges 的能力；启用设置时 mark range 热键会将 selection range 同步到点击或步进的 mark range。
- **Animating in Engine**：Snapper 标签页新增交换 child / parent 选择的按钮；Anim Tree 编辑器新增图形编辑支持，并通过 `ShowOnNode` 标记暴露动画节点描述属性。
- **Anim Mixer**：新增 FBX 导出与 Map Skeletal Motion to Root 功能，与动画编辑器功能对齐。
- **PCG**：生成资产的 PCG Primitives 上启用碰撞选项。
- **媒体与导出**：UEMHC 睫毛贴图导出为 RGBA 并提供默认暗棕色色调；MoviePipeline 可注入主 RGBA 层；ImgMedia DDS image media reader 支持 BC6H HDR。
- **Nanite**：为 Nanite Assemblies 实现 material usage flag，并支持材质 section highlighting。
- **其它渲染与编辑器**：PostProcess 支持在 renderer settings 设置项目级默认 tone curve；Lumen hit-lighting 改进；Transform2D Gizmo 增加列出所有工具与快捷键的扩展工具提示；Outliner 将 GUID/name accessors 与 Find References 提升到公共基类，Functions outliner 获得查找引用能力；Group Paint Tool 新增隔离选择与对称绘制；MediaIOFramework 在 Timecode sample evaluation 降级为 Platform Time 时新增警告，并在 CaptureCardMediaSource tooltips 中说明 Just-In-Time Rendering、Sample Evaluation Type 与 Framelock 要求。
- **平台与工具**：添加对 Xcode 27 的编译支持；Xbox Live / GDK 支持 2017 模式成就进度百分比与排行榜（并设置正确排行榜模式）；UnrealTraceServer 发布 1.25；AIE Time Posing 重新设计激活种子逻辑，在 `FTimePosingSequencerExtension::SetActive` 中统一解析种子，消除与曲线编辑器适配器的竞争条件并改进居中行为；为 identity GDK 添加 PIE user refreshed delegate。
- **其它底层能力**：Proxy Table 新增行分组（无需虚拟行即可组织条目）；为自定义结构体 pin 控件与可编辑性增加 RigVM 扩展点，新增可读取控制台变量的函数；ClassInfo 追踪支持 DisplayName；Apple 平台 Web 浏览器控件实现 cmd+x/cmd+c/cmd+v；新增支持多种姿态缓存格式的引擎底层机制。

## 🚀 重大变更

- **UAF 变量重构 Phase 1**：引入 Input / Internal / Local scopes、input variable context，以及 graph / Blueprint 访问支持。
- **UAF Attribute 体系重构**：`FAttributeBindingData` 改为 UObject 类型 `UUAFAttributeSchema`，减少引用计数开销并规避 AutoRTFM 问题；移除 `FAttributeNamedSetPtr` 与 `FAttributeTypedSetPtr`，改用引用。
- **PVE Export 流程重构**，并重组 PVE 模块与头文件结构。
- **大规模 API 重命名**：`AlignSequence` → `AlignWarp`；`Input Value` → `Use External Pose`；`FAttributeNamedSet` / `FAttributeTypedSet` → `FNamedSetSchema` / `FTypedSetSchema`；`GetInertializationRequestForGroup` → `FindInertializationRequestForGroup`；`UE_CLOG` 迁移到 `UE_CLOGF`。

## ⚡ 性能优化

- **UAF**：AssetRegistry 导出数据附加版本号并提供强制获取最低版本数据的 API，加速离线校验与同步；Attribute 绑定数据转为 UObject 后减少 ref-counting churn；属性模式与类型化集合容器合并为单个分配，减少分配次数与内存碎片。
- **Control Rig**：修复 FK Control Rig 初始化的 quadratic cost。
- **视口与编辑器交互**：修复关卡视口悬停行为在鼠标未移动时仍查询命中代理的问题，消除手柄飞行时的不必要计算；Shot Management 修复内容浏览器查看 Cinematic Assembly 资产时的大范围 AssetRegistry 查询卡顿；修复动画模式在不需要时绘制 Gizmo。
- **Direct Mesh Control**：网格未渲染时不更新网格对象或排队变形器工作；生成 DMC skms 时移除无用属性。
- **FInpaintSolver**：预计算 inpaint 能量矩阵并在多次属性传递间重用。
- **媒体与构建**：SwitchboardListener 避免日志刷新阻塞主线程；TmvMedia 修复转码回读过度分配并引入内存感知并发控制；Composite 减少 SSR input branch 中重复的 graph registration；PVE 导出结束时只刷新一次 viewports。
- **RigVM / UBT**：RigVM nativization 将 external variables 作为参数传入 extracted callables 改进代码生成；UnrealBuildTool 改为编译 UHT 与 VNI 工具声明的 `.gen.cpp` 文件，而非在生成代码仍在写入时扫描目录。

## 🔧 API 变更

- **导出与宏**：引擎、插件及 Runtime 中多处模块的导出宏被修复，确保跨 DLL 边界的类型正确导出；`UE_CLOG` 迁移到 `UE_CLOGF`；为 `SpringMath.h` 补回缺失的 `#pragma warning pop`。
- **RigVM**：重构 RigVM 函数 GUID 系统，并以此修复 FunctionHash 与可调用数据的 Cook 非确定性；进行小型 API 修复以提升 AI 友好性；新增自定义结构体 pin 控件与可编辑性扩展点。
- **UAF**：移除 `FAttributeNamedSetPtr` / `FAttributeTypedSetPtr`，改用 `FAttributeNamedSet&` / `FAttributeTypedSet&`；`FAttributeBindingData` 改为 `UUAFAttributeSchema` UObject；`FAttributeNamedSet` / `FAttributeTypedSet` 重命名为 `FNamedSetSchema` / `FTypedSetSchema`；Montage 组件 `GetInertializationRequestForGroup` 重命名为 `FindInertializationRequestForGroup` 并移至公共 API；`AlignSequence` 重命名为 `AlignWarp`；`Input Value` 节点重命名为 `Use External Pose` 并新增 anim node retarget 方法。
- **Sequencer / 编辑器**：`LevelSequenceEditor` 新增 `RestorePreAnimatedState` 与原生 `GetCurrentSequencer`；通过 `UMovieSceneSequenceExtensions` 将 `IsPlayableDirectly` / `SetPlayableDirectly` 暴露给蓝图与 Python；规范化绑定上下文标识符为干净一致的令牌（无前导 F、无空格）并提供人类可读显示名；`SStructureDetailsView` 支持 `bShowHeaders`，可隐藏分类头以与 `SDetailsView` 行为一致；扩展内容浏览器中"创建 Control Rig 资产"的 API，支持同时选择多个蓝图 Rig 批量创建。
- **动画**：动画节点描述属性可通过 `ShowOnNode` 标签暴露给 Anim Tree 编辑器。
- **Proxy Table**：对外暴露 `UProxyTable::FindProxyObject` 的软结果重载。
- **数学库**：增加 `FTransform` 的强制转换构造函数、`VectorRegisterCast` 泛型支持与多个缺失特化，补齐 `FTransform` 的 `Get/SetScale3DRegister`。
- **其它**：CowRef 简化，`ForceMutable` 合并入 `GetMutable` 以避免不当使用；PVE 将 shared headers 从 Private/ 移至 Internal/，mesh exporter 及其 helpers 移入 ProceduralVegetation 模块，export entry 移入 runtime 模块，改用 PVE 自己的 viewport type enum，并恢复 UnrealEd 对 runtime 模块的 include path；nDisplay Frame stats shader declaration 从 DisplayCluster 模块移至 DisplayClusterShaders 模块。

## ⚠️ 废弃预告

- **Sequencer**：marked frame range 相关 deprecations 的生效版本从 6.0 调整为 5.9。
