## 用途

Modeling Tools Editor Mode 是 UE5 内置的建模编辑器模式插件，为关卡编辑器提供一套完整的交互式网格创建与编辑工具集。它本身不包含具体工具的实现代码（那些在 `MeshModelingTools`、`MeshModelingToolsExp` 等插件中），而是作为**宿主编辑器模式（Editor Mode）**，负责：

1. **注册并管理所有建模工具**——将来自多个工具插件的 80+ 个工具统一注册到编辑器模式中
2. **提供工具面板 UI**——左侧工具栏按类别组织工具（创建、变形、UV、布尔运算、物理等）
3. **管理网格元素选择系统**——支持三角形/顶点/边/多边形组的交互式选择、变换、拖拽
4. **处理资产生成策略**——控制工具创建的 Static Mesh / Dynamic Mesh Actor / Volume 的存储路径和保存行为
5. **提供 Gizmo 数值输入、对齐吸附、压感笔支持**等编辑器集成
6. **支持第三方扩展**——通过 `IModelingModeToolExtension` 模块化特性接口，允许其他插件向建模模式注入自定义工具

简单来说：如果你想在 UE5 编辑器中直接建模（而非导入外部模型），这个插件就是入口。

## 使用场景

- 你需要在关卡中直接创建基础几何体（Box、Sphere、Cylinder 等） → 建模模式的 Primitives 分类
- 你需要对已有的 Static Mesh 进行布尔运算（并集、差集、交集） → Mesh Ops 分类
- 你需要雕刻网格表面（类似 ZBrush 的笔刷交互） → Deform 分类的 Sculpt 工具
- 你需要编辑 UV 布局、投射 UV、传递 UV → UVs 分类
- 你需要烘焙法线贴图、AO 等纹理贴图 → Baking 分类
- 你需要为网格设置碰撞体、编辑物理属性 → Physics 分类
- 你需要执行 LOD 生成和管理 → LODs 分类
- 你需要选择网格元素（顶点/边/面/多边形组）并对其执行挤出、偏移等操作 → Selection / Poly 分类
- 你需要在建模模式中使用自定义第三方工具 → 实现 `IModelingModeToolExtension` 接口

## 蓝图用法

本插件主要是一个 Editor Mode 框架，**不提供 BlueprintCallable 节点**。它的交互完全通过编辑器 UI 进行，不暴露给蓝图系统。

## C++ 用法

### 核心架构

本插件的核心是 `UModelingToolsEditorMode` 类，继承自 `UBaseLegacyWidgetEdMode`。它在 `Enter()` 中完成所有初始化：注册工具目标类型、创建 Gizmo 管理器、初始化选择系统、注册 80+ 个工具 Builder。

### 头文件引入

```cpp
#include "ModelingToolsEditorMode.h"
#include "ModelingModeToolExtensions.h"
#include "ModelingToolsEditorModeSettings.h"
```

### 激活建模模式

```cpp
// 通过编辑器模式管理器激活建模模式
FEditorModeTools& ModeManager = GLevelEditorModeTools();
ModeManager.ActivateMode(UModelingToolsEditorMode::EM_ModelingToolsEditorModeId);

// 获取建模模式实例
UEdMode* EditorMode = ModeManager.GetActiveScriptableMode(
    UModelingToolsEditorMode::EM_ModelingToolsEditorModeId);

// 获取工具管理器并启动特定工具
UInteractiveToolManager* ToolManager = EditorMode->GetToolManager();
ToolManager->SelectActiveToolType(EToolSide::Left, TEXT("BeginDrawPolygonTool"));
ToolManager->ActivateTool(EToolSide::Left);
```

*来源：`Tests/ExtrudePolygonCoreSmoke/ExtrudePolygon.spec.cpp`*

### 通过工具管理器程序化启动工具

```cpp
// 获取工具管理器
UInteractiveToolManager* ToolManager = EditorMode->GetToolManager();

// 启动 DrawPolygon 工具
ToolManager->SelectActiveToolType(EToolSide::Left, TEXT("BeginDrawPolygonTool"));
ToolManager->ActivateTool(EToolSide::Left);

// 获取活跃工具实例并操作
UDrawPolygonTool* PolygonTool = Cast<UDrawPolygonTool>(
    ToolManager->GetActiveTool(EToolSide::Left));
if (PolygonTool)
{
    // 程序化添加顶点
    PolygonTool->AppendVertex(FVector3d(0, 0, 0));
    PolygonTool->AppendVertex(FVector3d(0, 100, 0));
    PolygonTool->AppendVertex(FVector3d(100, 0, 0));
    PolygonTool->EmitCurrentPolygon();
}

// 完成并退出工具
ToolManager->DeactivateTool(EToolSide::Left, EToolShutdownType::Completed);
```

*来源：`Tests/ExtrudePolygonCoreSmoke/ExtrudePolygon.spec.cpp`*

### 扩展建模模式（注册自定义工具）

通过 `IModelingModeToolExtension` 模块化特性接口，你的插件可以向建模模式注入工具：

```cpp
#include "ModelingModeToolExtensions.h"

class FMyModelingExtension : public IModelingModeToolExtension
{
public:
    virtual FText GetExtensionName() override 
    { 
        return FText::FromString(TEXT("My Custom Tools")); 
    }

    virtual FText GetToolSectionName() override 
    { 
        return FText::FromString(TEXT("Custom")); 
    }

    virtual void GetExtensionTools(
        const FExtensionToolQueryInfo& QueryInfo,
        TArray<FExtensionToolDescription>& ToolsOut) override
    {
        FExtensionToolDescription Desc;
        Desc.ToolName = FText::FromString(TEXT("My Tool"));
        Desc.ToolBuilder = NewObject<UMyCustomToolBuilder>();
        ToolsOut.Add(Desc);
    }
};

// 在模块 StartupModule 中注册
void FMyModule::StartupModule()
{
    IModularFeatures::Get().RegisterModularFeature(
        IModelingModeToolExtension::GetModularFeatureName(),
        &MyExtension);
}
```

*来源：`Public/ModelingModeToolExtensions.h`*

### 配置建模模式设置

```cpp
#include "ModelingToolsEditorModeSettings.h"

// 获取项目级设置（Project > Plugins > Modeling Mode）
UModelingToolsEditorModeSettings* Settings = 
    GetMutableDefault<UModelingToolsEditorModeSettings>();

// 配置资产生成行为
Settings->SetAssetGenerationMode(
    EModelingModeAssetGenerationBehavior::AutoGenerateAndAutosave);
Settings->SetAssetGenerationLocation(
    EModelingModeAssetGenerationLocation::AutoGeneratedWorldRelativeAssetPath);

// 配置默认输出类型
Settings->DefaultMeshObjectType = EModelingModeDefaultMeshObjectType::DynamicMeshActor;

// 启用/禁用网格选择系统
Settings->SetMeshSelectionsEnabled(true);

// 配置 Gizmo 模式
Settings->bRespectLevelEditorGizmoMode = false;  // 使用 Combined Gizmo
```

*来源：`Public/ModelingToolsEditorModeSettings.h`*

## Demo 示例

### 最小化激活建模模式并启动工具

```cpp
// MyModelingHelper.h
#pragma once
#include "CoreMinimal.h"

class FMyModelingHelper
{
public:
    static void ActivateModelingModeAndCreateBox();
};
```

```cpp
// MyModelingHelper.cpp
#include "MyModelingHelper.h"
#include "EditorModeManager.h"
#include "ModelingToolsEditorMode.h"

void FMyModelingHelper::ActivateModelingModeAndCreateBox()
{
    // 激活建模模式
    FEditorModeTools& ModeManager = GLevelEditorModeTools();
    ModeManager.ActivateMode(UModelingToolsEditorMode::EM_ModelingToolsEditorModeId);

    UEdMode* ModelingMode = ModeManager.GetActiveScriptableMode(
        UModelingToolsEditorMode::EM_ModelingToolsEditorModeId);
    if (!ModelingMode) return;

    // 启动 Box 基础体工具
    UInteractiveToolManager* ToolManager = ModelingMode->GetToolManager();
    ToolManager->SelectActiveToolType(EToolSide::Left, TEXT("BeginAddBoxPrimitiveTool"));
    ToolManager->ActivateTool(EToolSide::Left);
}
```
