## ✨ 新功能
*   **WorldPartition**: 引入了 `FFixedGridInfo` 访问器，用于在编辑器时获取固定网格的元数据；同时为运行时 ISM 单元转换器添加了 `bStrictBucketing` 选项。
*   **MaterialIR**: 为自定义输出添加了表达式 getter 支持。
*   **PCG**: 为与编辑器交互的特定节点添加了事务支持（主要用于关卡资产图），并可通过 cvar 控制；支持类型擦除的 `Get/SetRange`；在数据覆盖面板列表视图中支持从右键菜单清除 Delta；确保纹理引脚的 `multi-data` 为 false 以避免 GPU 上创建过多采样器。
*   **动画系统**: 为动画录制添加了 `bRemoveExcludedCurves` 选项，以移除已录制但需要排除的曲线；为 Mass Representation 添加了分层动画支持；为 `UNavigationSystemV1` 添加了 `GetSupportedAgentNames()` 函数，以便在属性中使用下拉菜单选择代理名称；为 UAF Layering 注册了层栈作为动画节点支持的资产类型；为动画序列添加了同步元数据生成功能。
*   **Sequencer**: 支持为装饰和装饰区段进行复制/粘贴；将 `AddDefaultTracksForActor` 移至 `ULevelSequenceEditorSubsystem` 的公共方法，以便其他工具应用项目设置的默认轨道。
*   **Mutable**: 添加了骨骼网格体在骨骼层级中变换的节点。
*   **导航系统**: 为 `UNavigationSystemV1` 添加了 `GetSupportedAgentNames()` 函数，用于在属性中生成可用代理名称的下拉列表。
*   **其他**: 为 Modular Viewports 添加了辅助游戏实例和 Scene Viewport UMG；为 `profile blend` 添加了根空间支持；为曲线编辑器添加了将多个曲线粘贴到多个曲线的附加功能；为 `ZenStoreWriter` 添加了在烹饪期间为每个 bulkdata 载荷写出元数据的能力；添加了新的 `GetIoChunkTypeFromFlags` 工具函数。

## 🚀 重大变更
*   **LiveLinkHub**: 移除了对实验性插件设备的引用，并移除了 Timed Data 监控功能。Hub 现在会向客户端告知应使用的 `CustomTimestep`，但自身不会采用，以避免低时间步率影响视频和动画数据的处理。
*   **MoviePipeline**: 从 MRQ 中移除了累积景深 (ADOF) 支持。ADOF 未来将仅通过 Graph 和 Basic 配置提供。

## ⚡ 性能优化
*   **Shader PSO**: 允许 Shader PSO 预缓存在着色器数据不可用时优雅地失败，避免阻塞。

## 🐛 Bug 修复
*   **MeshTerrain**: 修复了在 ITF 修复属性缓存恢复后，本地变通方案与基类属性缓存 ID 冲突的问题。
*   **TedsOutliner**: 修复了调试器/发现功能。
*   **Metahuman Texture**: 修复了当异步构建线程运行时 `PlatformData` 被设为 `nullptr` 可能导致的崩溃。
*   **MoviePipeline**: 修复了在渲染期间队列发生变更时，`UMoviePipelinePIEExecutor` 可能发生的罕见崩溃。
*   **Virtual Shadow Map**: 修复了 `VirtualShadowMapCacheManager` 调试代码中 `FAppTime` 的 ensure 错误。
*   **集群并集**: 修复了内部加速结构的竞态条件。
*   **材质**: 修复了在 `test_set_and_get_static_switch_parameter` 测试中 `FMaterial::~FMaterial()` 的断言错误。
*   **SemanticSearch**: 修复了在非 AI 搜索模式下语义搜索分数仍会显示的 UI 错误。
*   **Niagara**: 修复了 `FStackIssue` / `FStackIssueFix` 唯一 ID 使用了依赖区域设置的标识符的问题。
*   **Sequencer**: 修复了首次为模块化控制装备设置关键帧时丢失选择的问题。
*   **动画**: 修复了设置为局部空间的加法动画类型影响曲线数据的问题。
*   **CoreUObject**: 修复了 `ProcessNewlyLoadedUObjects` 广播 `ECompiledInUObjectsRegisteredStatus::PreCDO` 的时机，确保其在所有结构体注册并链接之后、创建 CDO 之前立即发生。
*   **Mutable**: 修复了骨骼网格体引脚的多个问题。
*   **SLW**: 在启用前向渲染时，禁用了 SLW 深度预处理通道的速度输出。
*   **其他**: 修复了 `UEMHC` 导出工具属性编辑的撤销问题；修复了 `UEMHC` 服装工具应用结构体子属性编辑的问题；修复了加载光照环境时背景颜色的应用问题；修复了 Android EGL 在调整表面大小后重新设置 EGL 上下文的问题；修复了 `PlainProps` 中关于非链接结构体的新断言仅对非瞬态结构体触发；修复了 `UEMHC` 通过预览场景设置标签更改背景颜色的选项；修复了 Linux 游戏手柄断开通知中不断增长的用户/设备 ID 问题；修复了当启用 `net.EnableActorCountInStats` cvar 时，NetDriver 统计信息无法与 Iris 协同工作的问题；修复了 `File Sandbox` 中重置已删除文件时间戳的问题；修复了某些烘焙热修复在没有后端热修复存在时无法应用的问题；修复了 `AutoRTFM` 中，如果未调用 `autortfm_initialize()` 则 `autortfm_shutdown()` 应为空操作；修复了在 `transaction` 中设置 `TimerIndicesByObjectKey` 以处理指向需要迁移到服务器的远程对象的情况；修复了 `UEMHC` 中导出工具属性编辑的撤销问题。

## 🔧 API 变更
*   **UnifiedError**: 重构并精简了公共 API，统一为一种声明和使用错误的标准方式。

## ⚠️ 废弃预告
*   **UnrealBuildTool**: 废弃了 `WindowsTargetRules` 中的 `bStrictPreprocessorConformance`，因为引擎无法在不严格遵守预处理器规范的情况下编译。
