# 2026年7月引擎更新月报

## ✨ 新功能

### UAF（Unreal Animation Framework）
- 新增 UAF Notify 运行时支持。
- 为蒙太奇添加初始 Anim Node 支持。
- UAFAnimGen 已集成到新的 UAF 运行时。
- 添加 `FUAFBlendSpacePlayerNode` 支持。
- 引入 `FMotionMatchingNode`，提供运动匹配的 Anim Node 实现。
- 为 `FUAFAlignSequencePostAnimOp` 添加简单平滑器，优化动画对齐。
- UAFPoseSearch 现在支持从 UAF 变量读取位置和朝向通道。
- 变量大纲和函数大纲中新增查看按钮，便于快速定位属性与函数。
- 变量类型选择器现在只显示 RigVM 支持的类型，避免创建节点时误选无效类型。
- 代理表编辑器新增搜索行、评论列、行重排及多项 UX 改进。
- UAF 查找结果支持双击打开，并可通过 `bAutoOpenFindResultsInSeparateTabs` 在新标签页打开。

### 动画工具与编辑器
- 动画交互编辑器新增补间工具：Scale To Neighbor Left、Blend To Neighbor Right。
- 引入时间姿态工具，支持通过四锚点加权范围编辑动画曲线。
- 动画层新增“提取选中”功能，可将当前层选中关键帧移动到新层。
- TextureGraph 资产创作工具集现已可用。
- 动画模式直接控制支持左键点击拖动，拖动时自动隐藏变换 Gizmo。
- Control Rig 的姿势库、动画层和约束选项卡在侧边栏停靠时改为展开/折叠，而非关闭。
- RigLogic 支持无界浮点曲线，用于面部动画。

### Sequencer
- 简单视图现在可以显示并关键帧组件通道。
- 运动扭曲新增可视日志调试绘制，可展示扭曲目标、修改器状态和逐帧增量。

### 合成系统（Composite）
- 为所有纹理选择器自动激活对应的媒体配置文件源，简化媒体源接入流程。
- `SCompositeEditorPanel` / `SCompositePassTree` 现在会记住每个图层的通道选择状态。
- 新增 2D 变换通道，并提供视口内交互式小工具，支持裁剪、柔化、缩放、旋转、翻转，可结合 Pilot+G 快捷键门控。

### Dynamic Wind
- 新增对 Cardinal Batched Animations 的裁剪功能，提升渲染性能。

### 其他
- MediaIO 新增交错输出的显示场同步，防止输出时场交替错乱。
- 集合编辑器中的集合可重新排序。

## 🚀 重大变更

- **UAF 分层**：默认生成模式更改为“仅动画节点”，可能影响依赖旧默认行为的项目。
- **动画模式**：为配合 Gizmo API 变更，暂时禁用点击拖动功能。

## ⚡ 性能优化

- **Dynamic Wind**：新增主批量动画剔除支持，减少不可见或无关动画的计算开销。
- **Lumen 辐照场采集**：优化探针插值计算，主机 900p 分辨率下耗时从 0.93ms 降至 0.76ms，节省约 0.17ms。
- **Lumen 辐射缓存**：移除 `ForceImmediateFirstBarrier` 标志（相关 RHI Bug 已修复），减少不必要的同步开销。
- **Mass 实体系统**：修复处理器实例重用逻辑，图形重建时正确复用已修剪实例，避免不必要的重置。
- **动画**：优化动画细节面板性能；新增 UAF AnimOps 与 RigVM/Control Rig 执行的 Insights 性能分析事件；当步幅缩放为 1 时不再标记组件空间姿势为脏。

## 🐛 Bug 修复

### 动画与 UAF
- 修复动画历史收集器因骨骼为空导致的断言崩溃。
- 修复使用抽象混合蒙版且未找到匹配集时的不稳定断言。
- 修复动画层重复键无法在覆盖层上正常工作的问题。
- 修复绑定选取器工具在销毁过程中访问已释放状态的问题。
- 确保四元数属性在基本运算中保持归一化。
- 修复加性重定向相关问题。
- 修复 UAFPoseSearch 缺少 UAFMirroring 插件依赖的问题。
- 修复未连接节点可能触发的断言。

### Control Rig
- 修复重布线节点中访问空引脚数组导致的崩溃。
- 修复 Sequencer 中使用绑定、更改变量后加载序列时的崩溃。
- 修复修改变量范围时及保存时的崩溃。
- 修复删除蓝图组件时重建 Control Rig 参数区段可能遇到的空指针崩溃。
- 从 `FRigUnit_CopyModuleProxyVariables` 移除 `Hidden` 元数据（见 API 变更）。

### Sequencer
- 修复动画混合器中根偏移 Gizmo 在世界空间下的行为，尤其针对偏离 Actor 根部的网格。
- 修复使用 Gizmo 编辑后根运动回退 Actor 位置的问题。
- 修复运行时总线拓扑更改后，总线区段显示绑定姿势的问题。
- 修复 ECS 下切换自动烘焙时 Control Rig 丢失骨骼网格绑定的问题。

### Dynamic Wind
- 修复低速风时叶片振动过强的问题，并增加全局风的随机变化，使表现更自然。
- 补提缺失的着色器文件，并恢复种子数据跳过屏障的标志。

### 合成（Composite）
- 修复场景捕获（如 ShadowReflection）激活时 Render Target Extraction Pass 永久冻结的问题。
- 修复未初始化的标量 `SLATE_ARGUMENT` 成员，避免潜在未定义行为。

### 构建与平台
- 修复在已安装引擎版本中构建插件时，因缺少 ImportLib stub `.so` 导致链接失败的问题。
- 修复启用 IOStore 时 `-createchunkinstall` 错误地将非 chunk-0 的 `.utoc`、`.ucas`、`.sig` 和 `.uondemandtoc` 文件排除出最终安装包的问题。
- 修复 `UbaJobProcessor.cpp` 部分合并导致缺少依赖更改的集成问题。
- 恢复 `FPaths::IsStaged()` 中的 `RequiresCookedData()` 子句，修正先前部分集成引入的逻辑缺失。

### 渲染与着色器
- 修复稳定 PSO 缓存序列化中的未对齐读取问题（`FShaderHash` 从 SHA1 迁移到 XXH64 后引入）。
- 修复 GPU Niagara 条带在浮点 `RibbonLinkOrder` 下链接顺序被打乱的问题。
- 修复编辑器中缩略图读取的竞争条件。
- 修复撤销事务期间应用根集材质检查的问题。

### Mass、网络与物理
- 修复 Mass 角色生成时的顶级崩溃，`UMassAgentComponent` 处于意外注册状态时现在会优雅恢复。
- 修复网络物理在重新模拟时运行注销对象 Lambda 的异常逻辑，并将 `AddUnique` 回退为 `Add`。

### 其他
- 修复 `FMacCursor::CreateCursorFromRGBABuffer` 因步幅计算错误及 `FColor` RGBA 到 ARGB 通道混合不当导致的图像破损。
- 修复非编辑器（打包）版本无法选择非默认音频输出设备的问题。
- 修复代理表编辑器因过时 UI 导致行内容显示错误及潜在崩溃。
- 修复 PCG 删除属性节点错误移除未受影响域数据的问题。
- 修复 Lumen 辐照场探针样本位置偏移量的计算错误，该错误可能影响插值质量与光照数据准确性。

## 🔧 API 变更

- **蒙皮场景扩展（Skinning Scene Extension）**：新增 Provider Phases，用于控制蒙皮计算在渲染管线中的执行时机。Dynamic Wind 可在渲染阶段执行蒙皮，常规路径仍在场景更新阶段执行以满足依赖需求；毛发皮肤缓存系统依赖早期管线中的骨骼变换，通过 Phases 机制可正确协调执行顺序。
- `UMovieSceneControlRigParameterTrack` 新增 `FindEvaluatedGameWorldControlRig()` 方法，用于在游戏世界中查找已计算的 Control Rig 实例。
- 从 `FRigUnit_CopyModuleProxyVariables` 移除 `Hidden` 元数据，使其可在编辑器中直接查看。
- 绑定值映射的内部访问改为使用 `GetValue`/`SetValue`，替代 `operator[]`。
