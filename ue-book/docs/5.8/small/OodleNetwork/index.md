## 用途

Oodle Network 是 UE5 网络数据包压缩系统的核心插件，基于 Oodle 压缩库实现 UDP 网络数据包的字典压缩。

这个插件解决的核心问题是：多人游戏中的网络带宽瓶颈。UE5 的网络传输会产生大量 UDP 数据包，尤其是 Actor 同步、RPC 调用等场景。Oodle Network 通过预训练的字典（dictionary）对数据包进行压缩，可以显著减少网络带宽消耗（典型场景下节省 50%+ 的带宽）。

**工作原理**：
1. 使用 `OodleNetworkTrainerCommandlet` 对真实游戏网络流量进行采集（`.ucap` 文件）
2. 通过 Oodle 训练 API 从采集数据中生成压缩字典（`.udic` 文件）
3. 运行时服务器和客户端加载相同字典，对每个数据包进行压缩/解压
4. 字典基于游戏实际网络模式训练，因此压缩率远高于通用压缩算法

**架构位置**：作为 UE 的 `PacketHandler` 系统的一个组件（`HandlerComponent`），无缝集成到网络栈中，对上层完全透明。

## 使用场景

- 你在开发多人在线游戏，需要减少网络带宽消耗 → 使用 Oodle Network
- 你的游戏有大量 Actor 同步数据需要传输 → 训练自定义字典获得最佳压缩率
- 你需要在开发阶段采集网络数据包用于分析 → 使用 PacketCapture 功能
- 你需要在不同平台/客户端间选择性启用压缩 → 使用 `EOodleNetworkEnableMode`

## 蓝图用法

Oodle Network 是一个纯 C++ 运行时插件，不暴露蓝图节点。它在网络栈底层自动工作，无需蓝图交互。

配置通过 CVar 控制：

| CVar | 说明 |
|---|---|
| `net.OodleEnableMode` | 控制服务器端压缩启用模式 |
| `net.OodleClientEnableMode` | 控制客户端压缩启用模式 |
| `net.OodleMinSizeForCompression` | 最小压缩包大小阈值 |

## C++ 用法

Oodle Network 在运行时自动工作，通常不需要直接编写 C++ 代码。以下说明如何进行高级配置和字典管理。

### 头文件引入

```cpp
#include "OodleNetworkHandlerComponent.h"
```

### 检查压缩状态

通过 `OodleNetworkHandlerComponent` 检查当前压缩是否激活：

```cpp
// 获取当前网络驱动的 PacketHandler，再查找 Oodle 组件
// 来源: Source/Public/OodleNetworkHandlerComponent.h - IsCompressionActive()
UOodleNetworkHandlerComponent* OodleComponent = /* 从 PacketHandler 获取 */;
if (OodleComponent && OodleComponent->IsCompressionActive())
{
    // 压缩已启用，网络数据包正在被 Oodle 压缩
}
```

### 压缩启用模式

```cpp
// 来源: Source/Public/OodleNetworkHandlerComponent.h
enum class EOodleNetworkEnableMode : uint8
{
    AlwaysEnabled,                   // 强制启用压缩
    WhenCompressedPacketReceived     // 仅在收到压缩包时启用（按需）
};
```

### 字典路径解析

```cpp
// 来源: Source/Public/OodleNetworkHandlerComponent.h - GetDictionaryPaths()
FString ServerDictPath, ClientDictPath;
bool bSuccess = OodleComponent->GetDictionaryPaths(ServerDictPath, ClientDictPath, true);
if (bSuccess)
{
    // ServerDictPath: 服务器字典文件路径
    // ClientDictPath: 客户端字典文件路径
}
```

### 错误处理

```cpp
// 来源: Source/Public/OodleNetworkFaultHandler.h
enum class EOodleNetResult : uint8
{
    Unknown,
    Success,
    OodleDecodeFailed,          // 解码失败
    OodleSerializePayloadFail,  // 负载序列化失败
    OodleBadDecompressedLength, // 解压长度溢出
    OodleNoDictionary           // 字典缺失
};
```

## 使用 OodleNetworkTrainerCommandlet

这是生成压缩字典的命令行工具，是使用 Oodle Network 的关键步骤：

```bash
# 来源: Source/Classes/OodleNetworkTrainerCommandlet.h
# 自动生成字典（推荐方式）
UE5Editor-Cmd.exe ProjectName -run=OodleNetworkTrainerCommandlet AutoGenerateDictionaries

# 合并数据包文件
UE5Editor-Cmd.exe ProjectName -run=OodleNetworkTrainerCommandlet MergePackets Output.ucap File1.ucap,File2.ucap

# 手动生成字典
UE5Editor-Cmd.exe ProjectName -run=OodleNetworkTrainerCommandlet GenerateDictionary Output.udic Filter All PacketFile.ucap
```

**字典生成流程**：
1. 启动服务器并运行游戏，Oodle 会自动采集网络数据包到 `{Game}/Saved/Oodle/Server/` 目录
2. 确保采集数据量达到约 100MB 以上
3. 运行 `AutoGenerateDictionaries` 命令
4. 字典文件输出到 `{Game}/Content/Oodle/` 目录
5. 客户端和服务器都需要加载相同的 `.udic` 文件

## Demo 示例

以下展示如何自定义 Oodle 训练参数（通过配置文件）：

```cpp
// DefaultOodleNetwork.ini
[/Script/OodleNetworkHandlerComponent.OodleNetworkTrainerCommandlet]
bCompressionTest=true
HashTableSize=19
DictionarySize=16384
DictionaryTrials=4
TrialRandomness=50
TrialGenerations=3
bNoTrials=false
```

自定义字典文件路径：

```cpp
// DefaultEngine.ini
[/Script/OodleNetworkHandlerComponent.OodleNetworkHandlerComponent]
# 自定义字典路径（默认在 Content/Oodle/ 下）
ServerDictionary=Game/Content/Oodle/GameInput.udic
ClientDictionary=Game/Content/Oodle/GameOutput.udic
```

选择性禁用压缩（某些平台）：

```cpp
// DefaultEngine.ini
[/Script/OnlineSubsystemUtils.IpNetDriver]
# 在特定平台上禁用 Oodle 压缩
OodleEnableMode=WhenCompressedPacketReceived
```
