# 2025年9月引擎更新月报

9 月是 **Iris 从正式版梳理为「Beta 标记」** 的月份（之后的稳定化阶段）。同时，**CoreUObject 的 `constinit` UObject 支持**、**Metal RHI 的内联光线追踪**、**Substrate 的 EON 粗糙漫反射**、**Heterogeneous Volume 的 Beta 晋升** 等，运行时基础周边的前进接连出现。

**Nanite 的第一人称 VSM／骨骼网格体装配扩展**、**PCG 的独立图表执行与 Editor Mode 强化**、**Chaos 的 `PullData` 最大 7 倍 / `PushData` 最大 15%** 等，性能改进的累积也在继续。

**移动端默认切换为 Deferred 着色**、**新 TRS Gizmo 默认启用**、**删除面向 32 位平台的 Malloc**、**旧 VR 编辑器模式弃用** 等，也包含了具有破坏性、需要迁移的变更。

## ✨ 新功能

**CoreUObject 支持 `constinit` UObject 变量**

> UHT 生成的代码中可以使用 `constinit` UObject 变量了，通过编译时初始化来削减启动时间和内存使用量的基础已引入。将来也有望成为热重载的替代方案。
>
> _出处: [2025-09-05](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/46)_

**Metal RHI 支持内联光线追踪**

> 在 macOS / iOS 上可以从计算着色器直接执行光线追踪了，Apple 平台上的渲染技术选择范围扩大了。
>
> _出处: [2025-09-04](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/45)_

**新增 Virtual Texture Collection 资产**

> 引入了一种将多个纹理捆绑到单一物理图块图集中的新资产类型，无需 UV 重映射即可高效采样。可以降低大规模纹理集的内存和管理成本。
>
> _出处: [2025-09-04](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/45)_

**OpenXR 原生支持 Space Warp / Frame Synthesis**

> Meta Quest 的 `XR_FB_space_warp` 和 `XR_EXT_frame_synthesis` 已在引擎侧支持，在移动 VR 中即使性能下降也更容易通过帧插值维持高帧率。
>
> _出处: [2025-09-04](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/45)_

**Substrate 新增 EON 粗糙漫反射模型**

> 遵循物理正确的微表面结构和能量守恒定律的新粗糙漫反射 BRDF。通过 `r.Substrate.EnergyConservation 1` 启用。
>
> _出处: [2025-09-22](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/62)_

**Substrate Format=1 的 SSS / Path Tracer 内部散射强化**

> Substrate 的 closure 数量现在可以从项目设置中控制，Path Tracer 侧则支持折射介质内部的体积散射，玻璃和液体表现得到改善。
>
> _出处: [2025-09-12](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/53) / [2025-09-25](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/65)_

**Nanite 装配支持骨骼网格体 + 第一人称 VSM**

> 在 `NaniteAssemblyEditorUtils` 中添加了骨骼网格体专用构建器，角色类资产也可以使用 Nanite 装配了。此外，第一人称视角 Actor 表现中可以使用 Nanite Virtual Shadow Maps，能够在 FPS 用的武器、手臂网格体上添加高质量动态阴影。
>
> _出处: [2025-09-06](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/47) / [2025-09-23](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/63)_

**Chaos Cloth: 基于 SkeletalMesh 的布料模拟**

> Chaos Cloth Asset 支持基于 Skeletal Mesh Component 的模拟和 Clothing Interactor。可以使用现有骨骼网格体直接进行集成工作流了。
>
> _出处: [2025-09-04](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/45)_

**PCG: 独立执行与新节点群**

> 现在无需分配给 Actor 组件即可单独执行 PCG 图表，可以从内容浏览器或调试面板直接生成和迭代。新增了大量实用节点，如 `SceneCapture` / `SaveTextureToAsset` / `Generate Landscape Textures`（基于 GPU）等。
>
> _出处: [2025-09-03](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/44) / [2025-09-05](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/46) / [2025-09-08](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/49)_

**PCG Editor Mode 的绘画/工具强化**

> 在可以直接在视口中绘画和绘制样条线的 Editor Mode 中，新增了新绘画工具、基于规则的射线检测过滤器、网格流送模式、笔刷旋转（鼠标滚轮）/ 立方体笔刷等，使交互式程序化生成更加易用。
>
> _出处: [2025-09-18](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/58) / [2025-09-23](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/63) / [2025-09-26](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/66) / [2025-09-29](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/69)_

**Sequencer / Control Rig 的选择集功能**

>
> _出处: [2025-09-07](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/48) / [2025-09-20](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/60)_

**Verse: 任务组、持久 weak_map、任务优化**

> VVM 中加入了 `VTask::AddToTaskGroup`/`RemoveFromTaskGroup`、`VTask::DeferOpen`、持久化 `weak_map` 支持、`<native><constructor>` 函数的报错处理、默认初始化器内 `<reads>` 放宽、复制类型约束强化等。

> _出处: [2025-09-03](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/44) / [2025-09-11](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/52) / [2025-09-12](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/53) / [2025-09-17](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/57) / [2025-09-18](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/58)_

**Niagara SimCache 支持所有浮点类型插值**

> SimCache 的插值功能默认支持所有基本浮点类型。使用时间样本的 Movie Render Queue 渲染质量将大幅提升。

> _出处: [2025-09-08](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/49)_

**Audio: Render Scheduler 默认启用**

> 新的音频渲染后端调度器默认启用，在内容密集的情况下音频性能和线程并行性得到改善。可通过 `au.UseRenderScheduler 0` 禁用。

**Multi-Server Replication 支持 Iris**

> 在 Iris 上支持 OnRep / RPC 禁用以及代理→客户端的 role 切换，多服务器环境中的复制选择范围扩大了。

**MetaHuman Animator: 基于语音的情感 (Emotion) 解析**

> 在从音频生成面部动画时新增了情感解析，可以根据语音语调生成更具表现力的表情。

**glTF 导出器支持变形目标**

## 🚀 重大变更

**Iris 复制框架整理为 Beta**

> 从 8 月的 Experimental→正式版处理，9 月明确整理为 Beta 标记。同时从引擎构建中移除了 `UE_WITH_IRIS` 预处理器，包括 Lyra 在内不再有区分 Iris 有效/无效的分支位置。
>
> _出处: [2025-09-08](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/49) / [2025-09-17](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/57)_

**移动平台默认切换为 Deferred 着色**

> 移动端默认渲染路径从 Forward Shading 更改为 Deferred Shading。同时本地光源的模板剔除默认禁用，`ShadingModelsMask` 可按平台设置，面向移动端的渲染设计基线发生了重大变化（VR 模板仅在移动端保持 Forward）。
>
> _出处: [2025-09-03](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/44) / [2025-09-08](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/49) / [2025-09-16](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/56)_

**新 TRS Gizmo 默认启用（选择退出方式）**

> 基于 Interactive Tools Framework 的新变换 Gizmo 在整个编辑器中从选择加入切换为选择退出。需要旧 Gizmo 的特定编辑器已单独禁用。
>
> _出处: [2025-09-22](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/62) / [2025-09-29](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/69)_

**Enhanced Input 与旧版输入集成**

> Enhanced Input 和旧版输入的处理已集成，Input Component 栈现在以正确的顺序只处理一次。栈迭代处理减半，旧版混用时的行为也变得可预测且确定。更容易分阶段迁移到 Enhanced Input。
>
> _出处: [2025-09-29](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/69)_

**删除面向 32 位平台的 Malloc 实现**

> 从 MallocBinned / MallocStomp 等各种分配器中删除了面向 32 位的支持代码，引擎已针对 64 位环境进行优化。
>
> _出处: [2025-09-29](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/69)_

**Heterogeneous Volume 晋升为 Beta**

> 阴影投射默认启用，现在无需重启编辑器即可切换启用状态。可伸缩性设置也已更新，使用初始设置即可获得更好的结果。
>
> _出处: [2025-09-17](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/57) / [2025-09-26](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/66)_

**Landscape Patch / SVG Importer / Media Viewer / Motion Design 相关功能成熟**

> Landscape Patch 插件从 Experimental 晋升为正式版，SVG Importer 进入 Virtual Production 的 Beta，Media Viewer 插件从 Experimental 移动到正式 Media 文件夹。
>
> _出处: [2025-09-04](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/45) / [2025-09-09](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/50) / [2025-09-19](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/59)_

**UAF (Unreal Animation Framework) 扩展支持非 RigVM 和程序化**

> 为在 `UAnimNextComponent` 上运行任意 Animation 资产进行了大幅重构，添加了仅用原生代码构建系统而不经过 RigVM 的路径。下一代动画系统的方向更加明确。
>
> _出处: [2025-09-25](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/65)_

**Sequencer 的静音/独奏与轨道实例绑定焕新**

> 静音/独奏状态已迁移到基于 `UMovieSceneMuteSoloDecoration`，并附加到文件夹、绑定、轨道单位，支持 Undo/Redo。轨道实例绑定和属性解析也引入了「volatile 路径」概念，整理了对数组和实例化结构体的安全访问。
>
> _出处: [2025-09-03](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/44) / [2025-09-04](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/45)_

**macOS 的 WebBrowser 后端切换为 WKWebView**

> 从 CEF3 切换到 WKWebView，还支持 3D UI 输入的手动 JavaScript 分派。

**Mobile Reflection 分离为独立着色路径**

> 在移动渲染中，所有反射已从主光源像素着色器分离为独立着色路径。主光源的着色器排列数量减少到约 1/10，改善了移动端性能和构建时间。
>
> _出处: [2025-09-09](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/50)_

**EOS SDK 更新至 v1.18.0.4**

> Epic Online Services SDK 已升级到 v1.18.0.4，引入了各种接口改进和错误修复。
>
> _出处: [2025-09-17](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/57) / [2025-09-18](https://github.com/pafuhana1213/UnrealEngine-UpdateTrackerReport/discussions/58)_

**Mutable 核心库内部化**

> Mutable 的核心库（`MuT`/`MuR`）头文件已从 Public 移动到 Internal 文件夹，核心命名空间也从 `mu` 更改为 `UE::Mutable::Private`。这是朝着关闭引擎外部直接访问方向的 API 清理。
