## How It Works

1. GitHub Actions detects new plugins in `EpicGames/UnrealEngine` 5.8 branch
2. For each new plugin, source code is analyzed via GitHub API
3. LLM generates Chinese documentation with API tables, usage examples
4. Docs are committed to this repo automatically
