# Buoyancy

> Set of tools for adding buoyant behavior to objects which interact with water bodies generated by the Water plugin

| 属性 | 值 |

| 中文名 | 浮力系统 |

| 创建时间 | 2023-08-01 |
| 年龄标签 | 🆕（约 3 年） |

## 用途

本插件为基于 Chaos 物理求解器的浮力模拟系统，专门用于与 Water 插件生成的水体交互。它不是一个简单的"漂浮"视觉效果，而是一套完整的物理驱动浮力方案——在物理线程上计算物体的浸没体积、施加浮力和阻力，并通过中间相（midphase）修改器介入碰撞管线。

**核心能力**：
- 通过 Chaos 中间相修改器检测刚体与水体的碰撞，精确计算浸没体积
- 支持三种水体采样模式：恒定样条（河流）、浅水模拟（烘焙数据）、带 Gerstner 波浪的样条（海洋/湖泊）
- 对 Box 和 Convex 两种碰撞形状执行细分体积计算
- 为布料（Chaos Cloth）提供水下浮力场（`FBuoyancyField`）
- 通过接口回调通知游戏逻辑水面接触事件

**为什么存在**：Water 插件负责生成水体几何形状和视觉效果，但不提供物理浮力。本插件填补了这一空白，让刚体和布料能够物理正确地浮在水面上、被水流推动、在波浪中起伏。

## 使用场景

- 你在做一个水面航行游戏（船、漂浮物） → 需要物体物理正确地浮在 Water 插件的河流/湖泊/海洋上
- 你在做一个水下场景，物体需要被水流推动 → 水流速度会传递到浸没物体上
- 你需要检测物体何时进入/离开水面 → 使用 `IBuoyancyEventInterface` 获取接触事件
- 你在使用 Chaos Cloth 布料模拟，需要布料浸入水中时有浮力效果 → 使用 `FBuoyancyField`

**前提条件**：必须启用 Water 插件和 ChaosUserDataPT 插件。

## 蓝图用法

### 核心接口

本插件的主要蓝图交互通过 `IBuoyancyEventInterface` 接口实现。你需要在 Actor 或 Component 上实现此接口来接收水面接触回调。

| 节点 | 说明 | 所在类 |
|---|---|---|
| `OnSurfaceTouchBegin` | 物体首次接触水面时触发 | `IBuoyancyEventInterface` |
| `OnSurfaceTouching` | 物体持续接触水面时每帧触发 | `IBuoyancyEventInterface` |
| `OnSurfaceTouchEnd` | 物体离开水面时触发（完全浸没或完全出水） | `IBuoyancyEventInterface` |

每个回调提供以下参数：
- `WaterBodyActor` — 接触的水体 Actor
- `WaterComponent` — 水体的 PrimitiveComponent
- `SubmergedComponent` — 浸没物体的 PrimitiveComponent
- `SubmergedVolume` — 浸没体积
- `SubmergedCenterOfMass` — 浸没部分的质心
- `SubmergedVelocity` — 浸没部分的速度

### 使用示例

1. 创建一个 Actor，添加 Static Mesh Component 作为漂浮物
2. 该 Actor 需要实现 `IBuoyancyEventInterface` 接口
3. 在蓝图编辑器中，为 `OnSurfaceTouchBegin`、`OnSurfaceTouching`、`OnSurfaceTouchEnd` 实现自定义逻辑（如播放水花特效、播放入水音效）
4. 确保物体有 Chaos 物理模拟（勾选 Simulate Physics）
5. 场景中有 Water 插件的水体（河流、湖泊或海洋）
6. 启用 Buoyancy 插件（默认关闭，需手动启用）

## C++ 用法

### 头文件引入

```cpp
#include "BuoyancySubsystem.h"
#include "BuoyancyEventInterface.h"
#include "BuoyancyRuntimeSettings.h"
```

### 基本用法：实现浮力事件接口

实现 `IBuoyancyEventInterface` 来接收水面接触回调。

```cpp
// MyFloatingActor.h
#pragma once

#include "GameFramework/Actor.h"
#include "BuoyancyEventInterface.h"
#include "MyFloatingActor.generated.h"

UCLASS()
class AMyFloatingActor : public AActor, public IBuoyancyEventInterface
{
    GENERATED_BODY()

public:
    AMyFloatingActor();

    // IBuoyancyEventInterface - C++ Native 回调
    virtual void OnSurfaceTouchBegin_Native(
        UPrimitiveComponent* WaterComponent,
        UPrimitiveComponent* SubmergedComponent,
        float SubmergedVolume,
        const FVector& SubmergedCenterOfMass,
        const FVector& SubmergedVelocity) override;

    virtual void OnSurfaceTouching_Native(
        UPrimitiveComponent* WaterComponent,
        UPrimitiveComponent* SubmergedComponent,
        float SubmergedVolume,
        const FVector& SubmergedCenterOfMass,
        const FVector& SubmergedVelocity) override;

    virtual void OnSurfaceTouchEnd_Native(
        UPrimitiveComponent* WaterComponent,
        UPrimitiveComponent* SubmergedComponent,
        float SubmergedVolume,
        const FVector& SubmergedCenterOfMass,
        const FVector& SubmergedVelocity) override;
};
```

### 基本用法：查询浮力子系统

```cpp
// 获取浮力子系统实例
UBuoyancySubsystem* BuoySubsystem = GetWorld()->GetSubsystem<UBuoyancySubsystem>();

// 检查是否启用
if (BuoySubsystem && BuoySubsystem->IsEnabled())
{
    // 查询某个包围盒区域的水体信息
    FBox QueryBounds = MyComponent->Bounds.GetBox();
    FVector WaterPlaneLoc, WaterPlaneNormal, WaterPlaneVel;
    TArray<const TSharedPtr<FBuoyancyWaterSplineData>> WaterBodyData;

    bool bHitWater = BuoySubsystem->FindOverlappingWaterBodies(
        QueryBounds,
        true,  // ComputePlane
        WaterPlaneLoc,
        WaterPlaneNormal,
        WaterPlaneVel,
        WaterBodyData);

    if (bHitWater)
    {
        UE_LOG(LogTemp, Log, TEXT("Water plane at %s, normal %s, velocity %s"),
            *WaterPlaneLoc.ToString(),
            *WaterPlaneNormal.ToString(),
            *WaterPlaneVel.ToString());
    }
}
```

### 进阶用法：运行时配置浮力参数

通过 `UBuoyancyRuntimeSettings` 调整全局浮力参数。

```cpp
#include "BuoyancyRuntimeSettings.h"

// 获取运行时设置（可在项目设置 > Buoyancy 中配置，也可在 C++ 中修改）
const UBuoyancyRuntimeSettings* Settings = GetDefault<UBuoyancyRuntimeSettings>();

// 关键参数说明：
// Settings->bBuoyancyEnabled          - 全局浮力开关
// Settings->bKeepFloatingObjectsAwake  - 防止漂浮物体休眠
// Settings->WaterDensity               - 水密度，默认 1.0 g/cm³
// Settings->WaterDrag                  - 水阻力系数
// Settings->WaterLift                  - 水升力系数（控制舵效/滑行效果）
// Settings->MaxNumBoundsSubdivisions   - 包围盒最大细分次数
// Settings->SplineKeyCacheGridSize     - 样条缓存网格大小
```

### 进阶用法：动态启用/禁用浮力子系统

```cpp
UBuoyancySubsystem* BuoySubsystem = GetWorld()->GetSubsystem<UBuoyancySubsystem>();
if (BuoySubsystem)
{
    // 运行时禁用浮力（例如进入室内场景时）
    BuoySubsystem->SetEnabled(false);
    
    // 重新启用
    BuoySubsystem->SetEnabled(true);
}
```

## Demo 示例

以下示例展示一个简单的漂浮木板 Actor，实现浮力事件接口并在水面接触时播放音效。

```cpp
// FloatingPlank.h
#pragma once

#include "GameFramework/Actor.h"
#include "BuoyancyEventInterface.h"
#include "FloatingPlank.generated.h"

class UStaticMeshComponent;
class USoundBase;

UCLASS()
class AFloatingPlank : public AActor, public IBuoyancyEventInterface
{
    GENERATED_BODY()

public:
    AFloatingPlank();

    virtual void OnSurfaceTouchBegin_Native(
        UPrimitiveComponent* WaterComponent,
        UPrimitiveComponent* SubmergedComponent,
        float SubmergedVolume,
        const FVector& SubmergedCenterOfMass,
        const FVector& SubmergedVelocity) override;

    virtual void OnSurfaceTouching_Native(
        UPrimitiveComponent* WaterComponent,
        UPrimitiveComponent* SubmergedComponent,
        float SubmergedVolume,
        const FVector& SubmergedCenterOfMass,
        const FVector& SubmergedVelocity) override;

    virtual void OnSurfaceTouchEnd_Native(
        UPrimitiveComponent* WaterComponent,
        UPrimitiveComponent* SubmergedComponent,
        float SubmergedVolume,
        const FVector& SubmergedCenterOfMass,
        const FVector& SubmergedVelocity) override;

protected:
    UPROPERTY(VisibleAnywhere)
    UStaticMeshComponent* MeshComponent;

    UPROPERTY(EditAnywhere, Category = "Buoyancy|Effects")
    USoundBase* SplashSound;
};
```

```cpp
// FloatingPlank.cpp
#include "FloatingPlank.h"
#include "Components/StaticMeshComponent.h"
#include "Kismet/GameplayStatics.h"

AFloatingPlank::AFloatingPlank()
{
    MeshComponent = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("Mesh"));
    RootComponent = MeshComponent;

    // 必须启用物理模拟，浮力才能生效
    MeshComponent->SetSimulatePhysics(true);
}

void AFloatingPlank::OnSurfaceTouchBegin_Native(
    UPrimitiveComponent* WaterComponent,
    UPrimitiveComponent* SubmergedComponent,
    float SubmergedVolume,
    const FVector& SubmergedCenterOfMass,
    const FVector& SubmergedVelocity)
{
    // 入水瞬间播放水花音效
    if (SplashSound)
    {
        UGameplayStatics::PlaySoundAtLocation(
            this, SplashSound, SubmergedCenterOfMass);
    }

    UE_LOG(LogTemp, Log,
        TEXT("FloatingPlank: Entered water. Volume=%.2f, CoM=%s"),
        SubmergedVolume, *SubmergedCenterOfMass.ToString());
}

void AFloatingPlank::OnSurfaceTouching_Native(
    UPrimitiveComponent* WaterComponent,
    UPrimitiveComponent* SubmergedComponent,
    float SubmergedVolume,
    const FVector& SubmergedCenterOfMass,
    const FVector& SubmergedVelocity)
{
    // 持续接触水面时可用于更新特效（如尾迹粒子）
}

void AFloatingPlank::OnSurfaceTouchEnd_Native(
    UPrimitiveComponent* WaterComponent,
    UPrimitiveComponent* SubmergedComponent,
    float SubmergedVolume,
    const FVector& SubmergedCenterOfMass,
    const FVector& SubmergedVelocity)
{
    // 完全离开水面或完全浸没
    UE_LOG(LogTemp, Log,
        TEXT("FloatingPlank: Left water. Volume=%.2f"),
        SubmergedVolume);
}
```

## 模块依赖

从 `.uplugin` 的 Plugins 依赖和 Build.cs 的模块依赖提取。使用者的模块需要添加以下依赖：

### 维护评价

**活跃维护中**。该插件在 2026 年 4 月连续收到多次实质性更新，主要集中在：
- **物理精度改善**：半隐式阻力积分、阻力缩放修正
- **性能优化**：浮力计算优化
- **工程规范**：日志宏迁移

作为实验性插件，目前仍在积极开发和打磨中。浮力计算的物理模型仍在调整（阻力系数、升力系数），API 可能随版本变化。

**已知限制**：
- 默认禁用（`EnabledByDefault=false`），需手动在插件管理器中启用
- 依赖 Chaos 物理引擎，不支持旧版物理
- 标记为 `IsExperimentalVersion=true`，生产环境使用需谨慎
- 文档和蓝图示例较少，主要面向 C++ 用户

**推荐**：如果你需要物理精确的水面浮力交互，这是目前 UE5 官方唯一的浮力方案。虽然处于实验阶段，但由 Epic 维护且近期活跃更新，值得关注和尝试。
