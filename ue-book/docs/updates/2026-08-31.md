# 2026-08-31 引擎周报

## ✨ 新功能

- **PVE Mesh Import**：新增完整的网格导入管线，包括 static-mesh importer、PVMeshImport 节点、imported-mesh LOD 节点、MeshBuilder deformed-geometry 路径、graft provenance 与 graft-aware synthesis，以及 diff/diagnostic tooling 和可视化测试。
- **ImgMedia**：DDS image media reader 支持 BC6H HDR。
- **Nanite**：为 Nanite Assemblies 实现 material usage flag；支持材质 section highlighting。
- **Sequencer**：扩展 marked frames，添加 EndFrame 和创建 mark ranges 的能力，不再只支持单帧标记；Mark range hotkeys 在设置启用时会将 selection range 同步到点击或步进的 mark range。
- **UAF Layering**：添加 layer content providers，支持额外的 internal node input。
- **PVE**：为 ImportedMesh 到 Mesh pin 的连接自动插入 conversion nodes。
- **AIE**：为 identity GDK 添加 PIE user refreshed delegate。

## ⚡ 性能优化

- **Control Rig**：修复 FK Control Rig 初始化的 quadratic cost。
- **Composite**：减少 SSR input branch 中重复的 graph registration。
- **PVE**：导出结束时只刷新一次 viewports。
- **UnrealBuildTool**：改为编译 UHT 和 VNI 工具声明的 `.gen.cpp` 文件，而不是在生成代码仍然写入时扫描 generated code 目录。
- **RigVM nativization**：将 external variables 作为参数传入 extracted callables，改进代码生成。

## 🐛 Bug 修复

- **Control Rig**：修复 Reset All Transforms 未重置 nulls 和 sockets、空间 picker 失去窗口激活时未关闭、数字命名复制时递增不正确、FK Control Rig 的选择控制问题、comment 节点详情文本缺失、preview mesh 更改撤销失败、Modular Rig viewport overlay 忽略 Application Scale、Comment box 大小撤销未恢复、不同 widget mode 的控件同时选中时 gizmo 闪烁、字符串 pin 值包含换行产生 “Bad quoted string” 警告、视口拾取控制未清除旧选择、连接 Get Pose Cache 节点时分配 Pose Asset 崩溃、运行时资产右键菜单缺少 Comment 节点，以及重新启用 FKControlRig 名称清理。
- **Sequencer**：修复 FCurveEditor incomplete type 编译错误、channel 移除时曲线仍在 Curve Editor 导致的 ensure、EaseCurveTool open in tab 在第一个序列关闭后无响应、禁用 Auto Expand Curve Editor on Selection 后选择仍自动展开树、Popout Transport Controls 不再误弹出 Sequencer Details panel。
- **Media**：修正 Electra 和 MediaIO 的 10-bit YUV conversion matrices，保留 HDR media source precision，并修复 BlackmagicMedia 纹理采样初始化中的 OCIO cache race，以及 ImgMediaPlayer 在非 GameThread 上记录 source opened 事件导致的 ensure。
- **nDisplay**：修复 config data、cluster nodes 或 viewports 无法解析时的崩溃。
- **DDC**：加固 Zen client 以处理 malformed compact binary responses。
- **Curve Table**：修复 undo 后 rich curve models 悬空指针导致的崩溃，改为按 handle 解析。
- **Constraints**：修复动画评估期间 constraints evaluation graph 失效导致的 FAnimationEvaluator use-after-free。
- **Viewport Interactions**：修复 “Flight Camera Control Type” 设置未生效，以及 marquee Shift-dragging 失效。
- **EditorTRSGizmo**：防止非有限 angle 值传入 GizmoElementCircleBase 和 GizmoElementArc。
- **PCG**：修复 Polygon Operation 丢失 Data domain attribute value。
- **UAF**：为 blend anim ops 添加 mismatching value spaces 的错误处理。
- **AIE**：Time offset 现在保留曲线而不是 flatten；修复部分资产的对话框重复 CVAR 问题。
- **RigVM**：修复 array pins 详情面板中重复的 Add/Empty 图标，保持 execute pin 在 library node exposed pin list 首位，并保留 pin default value 的仅大小写变化。
- **D3D12**：修复 raytracing residency tracking 变更后 uniform buffers 的 residency 问题。
- **Shaders**：修复 shader Compilation Parameters 与 Conservative parameters 不匹配。
- **Editor**：Control Rig 以及任何编辑器编辑子对象的资产现在会出现在 Recent Assets 列表。
- **Composite**：对齐 Blueprint setters 与 editor property updates，并在 persistence test teardown 中保留 world context。

## 🔧 API 变更

- **PVE**：重组模块和头文件结构，将 shared headers 从 Private/ 移至 Internal/，将 mesh exporter 及其 helpers 移入 ProceduralVegetation module，将 export entry 移入 runtime module，并改用 PVE 自己的 viewport type enum。同时恢复 UnrealEd 对 runtime module 的 include path。
- **nDisplay**：Frame stats shader declaration 从 DisplayCluster module 移至 DisplayClusterShaders module。

## ⚠️ 废弃预告

- **Sequencer**：marked frame range 相关 deprecations 的生效版本从 6.0 调整为 5.9。
