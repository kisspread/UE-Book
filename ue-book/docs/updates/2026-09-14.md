# 2026-09-14 引擎周报

## ✨ 新功能

- **UAF 动画节点扩展**：新增 Override Asset Slot、CallFunction 动画节点，以及 FUAFAnimNode 上的 ReplaceChildren 函数，丰富了 UAF 运行时动画图表达能力。
- **Media 框架**：新增 10-bit RGB r210 采样与 shader 转换，支持 BlackMagic 采集卡的 RGB 4:4:4 格式输入。
- **Composure**：新增面向 agent 的编辑器脚本 API，提升合成工作流的自动化与可编程性。
- **Control Rig Promise 系统**：新增 FindPromise、FindPromisedElementLabel 等 API，支持通过 label 解析 promise，并扩展了 post-construct 派生与解析能力。
- **Movie Render Pipeline**：
  - 新增 PSD 输出支持（单层/多层），对应新的 MovieRenderGraphPSD 插件（需启用）。
  - 渲染预览窗口新增“Initializing” UI，在关卡加载、着色器编译期间提供反馈。
  - 新增 RHI Resource Snapshot 功能，可在指定帧或 VRAM OOM 时生成显存快照（.rhiresourcesnapshot），并集成至 Render Resource Viewer。
  - Console Variable 节点支持字符串型 cvar，并允许一次设置多个 cvar。
  - 图变量新增 “Restrict to Job” 属性，可排除 shot 覆盖。
  - 含连接属性的节点在细节面板中显示连接状态图标。
  - Deferred Panoramic Renderer 节点新增 180° 全景渲染能力。
  - 主图窗口集成渲染队列。
  - EXR 元数据增加系统与 GPU 内存统计。
- **Sequencer**：引入 Struct decorators，标记帧变为装饰容器；标记锁定行为调整为仅限制移动，其他编辑操作保持允许。
- **PropertyEditor**：FDetailWidgetRow 支持手动切换 Inline Edit Condition 可见性。
- **动画节点资产选择器**：提取共享组件，供 Graph editor 与 details panel 复用。
- **ASTP**：新增 per-sequence 与 per-pose GPU instance bounds 及 readback，并添加序列分配 API。
- **Windows ARM64 支持**：实现原生 ARM64 堆栈遍历，启动正确架构的编辑器可执行文件，更新 nvapi 至 r615。

## 🚀 重大变更

- **PSD SDK 迁移**：PSD SDK 从 PSDImporter 插件移至引擎级通用位置，供 Movie Render Graph 等模块使用，可能影响依赖该插件的现有项目。
