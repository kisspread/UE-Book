# 2026-08-10 引擎周报

## ✨ 新功能
- **Dynamic Wind 系统**：新增调试模式以可视化实例追踪内存和使用情况；在默认资产设置中引入沉降时间斜坡；增加了质量检查工具、基础网格截面以及通过尺寸推导的功能；分离了速度与振幅的 CVar，使其以不同速率变化；提供调试可视化、装配体收集和基于曲率的弯曲状态。
- **动画与 Rig**：允许动画树资产用作 RigVM 值（例如通过 UOL 绑定作为模块变量）；在 UAF Notifies 中暴露 `IsBlendingOut`；将 Pose Value Bundle 重定向工具添加到 UAF Value 运行时。
- **PCG Primitives**：在生成资产的 PCG Primitives 上启用碰撞选项。
- **媒体与导出**：为 UEMHC 睫毛贴图导出为 RGBA，并提供默认暗棕色色调以便在 DCC 工具中加载；MoviePipeline 可注入主 RGBA 层。
- **编辑器**：Transform2D Gizmo 增加了扩展工具提示，列出所有工具与快捷键。
- **平台支持**：添加了对 Xcode 27 的编译支持。

## ⚡ 性能优化
- **Shot Management**：修复在内容浏览器中查看 Cinematic Assembly 资产时因不必要的大范围资产注册表查询导致的性能卡顿。
- **SwitchboardListener**：避免日志刷新阻塞主线程。
- **TmvMedia**：修复转码回读的过度分配，并引入内存感知的并发控制。

## 🐛 Bug 修复
- **动画与 Control Rig**：在操作约束时更新非交互子项；修复 BPI Rig 差异对比时的崩溃；解决 Blueprint Control Rig 重名保留源函数引用的问题；修复 GetUserData 单元中因用户定义结构未注册而导致崩溃，并修正 `bFound` 输出错误；Constraints UI 的多项修复（按钮裁剪、维持偏移位置、分离器大小恢复）；UAFBlendTwoPerValueAnimOp 因重复绑定值映射导致的崩溃，改用 `FindOrAdd`；UAF 函数引用在打包时未能正确解析过时 GUID；RigVM Detail 面板数组引脚无法删除最后元素；Island Manager 数据损坏修复；VQS 变换类型对齐到 16 字节以避免崩溃。
- **Sequencer**：修复播放客户端销毁后解析序列绑定的崩溃；关闭时 `~FScopedTransaction` 解引用 GEditor 导致的崩溃；动画混合器在烘焙版本中遵守 Force Root Lock 抑制；在游戏线程评估 Actor 引用通道。
- **渲染与特效**：Nanite 构建断言修复（Keep Triangle Percent < 100 或 Trim Relative Error > 0 时），并解决体素和曲线簇的构建非确定性问题；Movie Render Pipeline 修复抗锯齿设为 "None" 时植被出现周期性锯齿的时序采样问题；DiaphragmDOF 尝试绑定未使用 mips 时的崩溃；Material 写入 Velocity 的验证错误及潜在 PSO 编译卡顿修复；Metal RT 修复同时指定 Any‑Hit 与 Intersection 时融合着色器阶段判断错误；Niagara 音频采样崩溃修复（样本计数缓冲区下溢）以及编辑器外任务挂起修复；VulkanRHI 移除不使用的宏并重新梳理图像获取信号量与栅栏逻辑。
- **媒体与捕捉**：BlackmagicMedia 多项既往问题修复；MediaIO 修复 Bob 去隔行器效果不佳及 10‑bit 格式扫描线平均错误；Composite 深度网格顶点对齐到像素中心，并停止在未加载 Media Profile 模块时断言；CaptureManager 修复 ffmpeg CFR 帧复制导致的 RGB/深度不同步；WASAPI Capture 使用正确的端点类型枚举麦克风输入。
- **构建与平台**：UnrealBuildTool 修复缺失文件导致 UHT 输出未包含在已安装构建中的问题，并排除输入缓存文件避免污染构建产物；修复 Android 部署时主 OBB 未打包的问题；修复 Steam 在 Android 上的打包；修复模块化车辆崩溃；解决了 Xcode 27 Beta 2 下的编译问题；修复特定平台上 ClusterTraceBricks 的代码生成缺陷；CoreUObject 移除哈希用户定义结构时错误的 ensure。
- **PCG / 程序化内容**：修复填充区域时属性分区返回顺序不一致的问题；移除 Get Mesh Terrain Primitive 中创建错误的默认通道参数；序列化零元素数据视图时不再触发 ensure；Grower 预设生长模式重启后重置的持久化问题修复。
- **地形与建模**：修复 Mesh Terrain 在极端镶嵌时崩溃；TEDS 层级树因重复 Widget 导致的 SListView 验证失败；LandscapeEditor 用空指针防护替换不安全的 check()；ModelingComponents 修复在组件已销毁的 ToolTarget 中提交网格时的崩溃。
- **其他**：Mutable 修复流式 LOD 时格式不匹配的崩溃以及获取材质任务中的数据竞争；LevelEditor 视口点击选择对 `LastProxy` 增加引用计数以避免空指针解引用；Curve Editor 拖拽操作增加空检查；Shot Management 资产查询性能修复；StateTree Advanced Copy 修复事件 GUID 随机生成导致复制失败的问题；DiaphragmDOF 绑定未使用 mips 的崩溃；MHC 在通过 UV 寻找对应关系前检查 NaN/Inf UV 值。
