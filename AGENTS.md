# AGENTS.md

## Repo overview

UE-Book — VitePress static site + LLM pipeline that auto-generates Chinese-language docs for 800+ UE5 plugins. Served at `kisspread.github.io/UE-Book/`.

## Package manager

**pnpm** (not npm). CI uses `pnpm install --frozen-lockfile`.

## Build order (critical)

```bash
node scripts/sync-manifest.mjs   # 1st — generates public/manifest.json + sidebar.json
pnpm docs:build                  # 2nd — NODE_OPTIONS='--max-old-space-size=10240'
node scripts/build-search-index.mjs  # 3rd — search index deployed to GH Pages
```

Running build without `sync-manifest.mjs` first → missing plugin metadata, broken filter/cards.

## Directory layout — content source

Content lives in `ue-book/docs/`, **not** `docs/` at root:

```
ue-book/docs/
  5.8/{small,medium,large,xlarge}/{PluginName}/index.md
  updates/YYYY-MM-DD.md          # weekly reports
  updates/YYYY-MM.md             # monthly translations
  libraries/index.md             # community submissions
  public/manifest.json           # generated by sync-manifest
  public/sidebar.json            # generated by sync-manifest
```

VitePress `srcDir` is `ue-book/docs`. Rewrites flatten `{ver}/{size}/{name}` → `{ver}/{name}` for clean URLs.

## 5.7 docs excluded from build

`srcExclude: ['**/5.7/**']` in `.vitepress/config.ts:33` — OOM workaround. Do not remove without testing memory.

## CI / GitHub Actions

- `deploy.yml` — build + deploy to GH Pages. Triggered by push to `master`, schedule, or `workflow_run` completion of other workflows. Needs **10GB swap** on CI.
- `generate.yml` — V2 pipeline. Manual dispatch with `python3 -m v2.run --version 5.8 [--force-all|--force Name]`. Required secrets: `GH_PAT`, `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`, `TG_BOT_TOKEN`, `TG_CHAT_ID`. Runs in `ue-book/` working directory.
- `weekly.yml` — daily `weekly_report.py`, commits to `updates/`
- `monthly.yml` — translates monthly reports from `pafuhana1213/UnrealEngine-UpdateTracker`, commits to `updates/`
- `library-submit.yml` — triggers on GitHub Issue label `library-submission`, runs `library_submit.py`

CI also needs: Python 3.12, Node 22, `gh` CLI, `langchain-openai langchain-core` (weekly/monthly/library).

## V2 pipeline (`ue-book/v2/`)

Python LangGraph pipeline: `scan → generate_modules → review → generate_index → finalize`.

```bash
python3 -m v2.run --version 5.8 [--force-all | --force PluginA,PluginB] [--max-duration 10000]
```

- Config: `config.py` loads overrides from `config_local.py` (gitignored).
- Auto-resumes from `v2/last_run.json`.
- Incremental by default — only generates new/updated plugins per `manifest.json`.
- Self-triggers next GitHub Actions run when timebox expires.
- Doc template enforced by `ue-book/harness.md`.

## Size & age conventions

| Size | Source files |
|------|-------------|
| small | < 21 |
| medium | 21–50 |
| large | 51–99 |
| xlarge | ≥ 100 |

| Age tier | Created |
|----------|---------|
| relic 🏛️ | ≤ 2016 |
| old 👴 | ≤ 2021 |
| fresh 🥩 | > 2021 |

These are used in the frontend filter (FilterBar.vue) and in `sync-manifest.mjs` category normalization.

## Theme customizations

Custom VitePress theme at `.vitepress/theme/`:
- `index.ts` — adds a top-of-page SPA navigation progress bar
- `custom.css` — card grid, filter bar, tag styling
- `components/HomeCards.vue` — fetches `manifest.json`, renders filterable card grid
- `components/FilterBar.vue` — search + chip filters (体量/版本/年代/分类)
- `components/PluginCard.vue` — individual plugin card with name_cn subtitle, version badge, tags

## File conventions

- `Plan.md` is gitignored (scratch notes)
- `ue-book/manifest.json` — master record mapping plugin name → `{generated_in, size, doc_path}`
- `ue-book/docs/public/manifest.json` — public-facing manifest consumed by HomeCards.vue
- `ue-book/docs/public/sidebar.json` — sidebar nav for multi-module plugins
- `scripts/search-ue.py` — standalone search client, downloads `search-index.json` from GH Pages, caches 24h in `~/.cache/ue-book-search/`
- All text files LF line endings (enforced by `.gitattributes`)
