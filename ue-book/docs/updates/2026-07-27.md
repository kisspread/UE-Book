# 2026-07-27 引擎周报

## ✨ 新功能

- **UAF 增强**
  - 新增 UAF Notify 运行时支持。
  - 为蒙太奇添加初始 Anim Node 支持。
  - UAFAnimGen 已集成到新的 UAF 运行时。
  - 添加 `FUAFBlendSpacePlayerNode` 的支持。
  - 引入 `FMotionMatchingNode`，提供运动匹配的 Anim Node 实现。
  - 为 `FUAFAlignSequencePostAnimOp` 添加简单平滑器，优化动画对齐。
  - UAFPoseSearch 现在支持从 UAF 变量读取位置和朝向通道。
  - 代理表编辑器新增搜索行、评论列、行重排和 UX 改进。
  - UAF 查找结果支持双击打开，并可通过 `bAutoOpenFindResultsInSeparateTabs` 设置在新标签页中打开。

- **动画交互编辑器**
  - 新增补间工具：Scale To Neighbor Left 和 Blend To Neighbor Right。
  - 引入时间姿态工具，允许通过四锚点加权范围编辑动画曲线。
  - 动画层新增“提取选中”功能，可将当前层的选中关键帧移动到新层。

- **动画工具**
  - TextureGraph 资产创作工具集现已可用。
  - 动画模式直接控制支持左键点击拖动，拖动时自动隐藏变换 Gizmo。
  - Control Rig 的姿势库、动画层和约束选项卡在侧边栏停靠时改为展开/折叠，而非关闭。

- **Sequencer**
  - 简单视图现在可以显示并关键帧组件通道。
  - 运动扭曲添加了可视日志调试绘制，可展示扭曲目标、修改器状态和逐帧增量。

- **其他**
  - MediaIO 新增交错输出的显示场同步，防止输出时场交替错乱。
  - RigLogic 现在支持无界浮点曲线用于面部动画。
  - 集合编辑器中的集合可重新排序。

## 🚀 重大变更

- **UAF 分层**：默认生成模式更改为`仅动画节点`，可能会影响依赖旧默认行为的项目。
- **动画模式**：为配合 Gizmo API 变更，暂时禁用了点击拖动功能。

## ⚡ 性能优化

- **Lumen** 辐射缓存：移除 `ForceImmediateFirstBarrier` 标志，因为相关的 RHI Bug 已被修复，减少了不必要的同步开销。
- **Mass** 实体系统：修复了处理器实例重用逻辑，现在在图形重建时会正确复用已被修剪的实例，避免了不必要的重置。
- **动画**：优化了动画细节面板的性能；添加了 UAF AnimOps 和 RigVM/Control Rig 执行的 Insights 性能分析事件；当步幅缩放为 1 时不再标记组件空间姿势为脏，以减少不必要的更新。

## 🐛 Bug 修复

- **Control Rig**
  - 修复了在重布线节点中访问空引脚数组导致的崩溃。
  - 修复了在 Sequencer 中使用绑定，更改变量后加载序列时可能发生的崩溃。
  - 修复了修改变量范围时的崩溃。
  - 修复了保存时的崩溃。
  - 修复了在删除蓝图组件时重建 Control Rig 参数区段可能遇到空指针的崩溃。

- **Sequencer**
  - 修复了动画混合器中根偏移 Gizmo 在世界空间下的行为，尤其对偏离 Actor 根部的网格。
  - 修复了使用 Gizmo 编辑后根运动回退 Actor 位置的问题。
  - 修复了运行时总线拓扑更改后，总线区段显示绑定姿势的问题。
  - 修复了在 ECS 下切换自动烘焙时 Control Rig 丢失骨骼网格绑定的问题。

- **Mass 生态系统**
  - 修复了 Mass 角色生成时的顶级崩溃，当 `UMassAgentComponent` 处于意外注册状态时现在会优雅恢复。

- **动画与 UAF**
  - 修复了动画历史收集器因骨骼为空导致的断言崩溃。
  - 修复了使用抽象混合蒙版且未找到匹配集时的不稳定断言。
  - 修复了动画层重复键无法在覆盖层上正常工作的问题。
  - 修复了绑定选取器工具在销毁过程中访问已释放状态的问题。
  - 确保四元数属性在基本运算中保持归一化。
  - 修复了加性重定向的相关问题。
  - 修复了 UAFPoseSearch 缺少 UAFMirroring 插件依赖的问题。

- **网络与物理**
  - 修复了网络物理在重新模拟时运行注销对象 Lambda 的异常逻辑，并将 `AddUnique` 回退为 `Add`。

- **其他**
  - 修复了 GPU Niagara 条带在浮点 `RibbonLinkOrder` 下链接顺序被打乱的问题。
  - 修复了未连接节点可能触发的断言。
  - 修复了非编辑器（打包）版本无法选择非默认音频输出设备的问题。
  - 修复了代理表编辑器因过时 UI 导致行内容显示错误及潜在崩溃。
  - 修复了 PCG 删除属性节点错误移除未受影响域数据的问题。
  - 修复了编辑器中缩略图读取的竞争条件。
  - 修复了撤销事务期间应用根集材质检查的问题。
  - 为动态风系统补提了缺失的着色器文件，并恢复了种子数据跳过屏障的标志。

## 🔧 API 变更

- `UMovieSceneControlRigParameterTrack` 新增 `FindEvaluatedGameWorldControlRig()` 方法，用于在游戏世界中查找已计算的 Control Rig 实例。
- 从 `FRigUnit_CopyModuleProxyVariables` 中移除了 `Hidden` 元数据，使其可在编辑器中直接查看。
- 绑定值映射的内部访问改为使用 `GetValue`/`SetValue`，以替代 `operator[]`。
