## 用途

`DataLinkJsonEditor` 模块是 `DataLink` 虚拟制片数据链接插件的编辑器扩展部分。它专门用于处理 JSON 数据，提供将 JSON 结构自动转换为 Unreal Engine 用户定义结构体 (`UUserDefinedStruct`) 的功能。该模块解决了在 Motion Design 或虚拟制片工作流中，需要快速、准确地根据外部 JSON 数据格式（如来自传感器、软件或其他服务的数据）在引擎内创建匹配的数据结构的需求，实现高效的数据驱动开发和可视化配置。

## 使用场景

- **虚拟制片数据桥接**：你正在开发一个实时虚拟制片系统，需要从外部控制软件（如 Unreal Remote Control、第三方传感器应用）接收 JSON 格式的实时状态数据。使用此工具可以快速将 JSON 数据模式转换为 UE 内部结构体，以便绑定到蓝图或材质参数上。
- **Motion Design 动态内容**：你在 Motion Design 项目中，需要处理动态生成或来自外部 JSON API 的配置数据（如控制粒子效果、动画参数）。此模块能帮助你为这些动态数据创建强类型的结构体，避免在蓝图中进行复杂的字符串解析。
- **原型开发与数据对接**：在开发初期，当数据格式（JSON）已经确定但 UE 内部类型尚未建立时，可以使用此工具快速生成对应的结构体骨架，加速原型开发过程。

## 蓝图用法

`DataLinkJsonEditor` 模块主要提供编辑器工具和配置界面，其核心蓝图可调用功能通常通过 `DataLink` 或 `DataLinkJson` 模块暴露，或者通过编辑器工具栏按钮触发。以下是此模块提供的核心编辑器交互功能：

### 核心节点（编辑器工具与操作）

| 节点 | 说明 | 所在类/位置 |
|---|---|---|
| `Make Structs From JSON` | 工具栏按钮/菜单操作。读取预览的 JSON 数据，并调用结构体生成流程。 | 工具栏菜单 (`FDataLinkJsonEditorMenu`) |
| `SDataLinkJsonEditorStructGeneratorConfig` | 弹出一个配置窗口，允许用户指定生成结构体的保存路径、前缀和根结构体名称。 | `SDataLinkJsonEditorStructGeneratorConfig` (Slate Widget) |
| `GenerateFromJson` | 静态函数，接收 JSON 对象和配置参数，执行实际的结构体生成。 | `FStructGenerator` |

### 使用示例（蓝图/编辑器操作描述）

1.  在编辑器中，打开与 `DataLink` 相关的工具栏或菜单。
2.  点击 “Make Structs From JSON” 按钮。
3.  弹出 `SDataLinkJsonEditorStructGeneratorConfig` 配置窗口。
4.  在窗口中设置：
    -   **路径 (Path)**：选择新生成的结构体资产要保存的项目目录。
    -   **前缀 (Prefix)**：为所有自动生成的结构体名称添加一个前缀（如 `FMyPlugin_`）。
    -   **根结构体名称 (Root Struct Name)**：为 JSON 数据根对象对应的结构体指定一个名称。
5.  点击 “Commit” 确认。
6.  插件会分析当前预览的 JSON 数据，并在指定路径下递归生成一系列 `UUserDefinedStruct` 资产，其字段结构与 JSON 键值对完全匹配。

## C++ 用法

### 头文件引入

```cpp
#include "DataLinkJsonEditorStructGenerator.h"
// 需要额外包含 JSON 模块的头文件
#include "Serialization/JsonTypes.h" 
```

### 基本用法

以下代码演示了如何使用 `FStructGenerator` 以编程方式从 JSON 生成结构体。
*(来源: Private/DataLinkJsonEditorStructGenerator.h)*

```cpp
#include "DataLinkJsonEditorStructGenerator.h"
#include "Serialization/JsonTypes.h"
#include "Dom/JsonObject.h"

// 假设你有一个 FJsonObject 对象，例如从网络或文件加载得到
TSharedPtr<FJsonObject> MyJsonObject = ...; 

// 配置生成参数
UE::DataLinkJsonEditor::FStructGenerator::FParams Params;
Params.JsonObject = MyJsonObject;
Params.BasePath = TEXT("/Game/DataStructures"); // 资产保存路径
Params.StructPrefix = TEXT("DT_"); // 结构体名称前缀
Params.RootStructName = TEXT("SensorData"); // 根结构体名称

// 执行生成
UE::DataLinkJsonEditor::FStructGenerator::GenerateFromJson(Params);
```

### 进阶用法

`FStructGenerator` 内部使用 `FStructKey` 来识别和复用相同的 JSON 结构，避免重复生成相同的结构体。当你需要更精细地控制生成过程（例如，仅为部分 JSON 数据生成结构体）时，可以实例化 `FStructGenerator` 对象并调用其内部方法。但 `GenerateFromJson` 静态方法是推荐的主要接口。

```cpp
// （概念性示例，非直接可编译）
UE::DataLinkJsonEditor::FStructGenerator Generator;
// Generator 内部会管理一个 GeneratedStructs Map，通过 FStructKey 去重
// 当处理一个嵌套的 JSON 对象时，它会递归调用 GetOrCreateStruct 来获取或创建对应的 UE 结构体
```

## Demo 示例

一个最小示例，展示如何在编辑器工具或命令行模式下调用 JSON 到结构体的转换。

```cpp
// JsonToStructDemo.h
#pragma once

#include "CoreMinimal.h"

class FJsonToStructDemo
{
public:
    static void ConvertSampleJsonToStruct();
};
```

```cpp
// JsonToStructDemo.cpp
#include "JsonToStructDemo.h"
#include "DataLinkJsonEditorStructGenerator.h"
#include "Serialization/JsonReader.h"
#include "Serialization/JsonSerializer.h"
#include "Dom/JsonObject.h"

void FJsonToStructDemo::ConvertSampleJsonToStruct()
{
    // 1. 准备一个示例 JSON 字符串
    const FString JsonString = TEXT(R"({
        "timestamp": 1234567890,
        "position": { "x": 1.0, "y": 2.5, "z": -0.3 },
        "tags": ["indoor", "static"]
    })");

    // 2. 解析 JSON 字符串
    TSharedPtr<FJsonObject> JsonObject;
    TSharedRef<TJsonReader<>> Reader = TJsonReaderFactory<>::Create(JsonString);
    if (!FJsonSerializer::Deserialize(Reader, JsonObject) || !JsonObject.IsValid())
    {
        UE_LOG(LogTemp, Error, TEXT("Failed to parse JSON."));
        return;
    }

    // 3. 配置生成参数
    UE::DataLinkJsonEditor::FStructGenerator::FParams Params;
    Params.JsonObject = JsonObject;
    Params.BasePath = TEXT("/Game/AutoGenerated");
    Params.StructPrefix = TEXT("AG_");
    Params.RootStructName = TEXT("EnvironmentSnapshot");

    // 4. 生成结构体
    UE::DataLinkJsonEditor::FStructGenerator::GenerateFromJson(Params);

    UE_LOG(LogTemp, Log, TEXT("Structs generated from JSON."));
}
```

## 模块依赖

基于模块名称和常见模式推断，`DataLinkJsonEditor` 模块很可能依赖以下模块。实际依赖请以 `DataLinkJsonEditor.Build.cs` 文件为准。

|---|---|
| `DataLinkJson` | 提供 `DataLink` 插件的 JSON 数据处理核心功能。 |
