## ✨ 新功能
- **MaterialIR**：为自定义输出添加了表达式 getter 支持，增强了材质编辑器的灵活性。
- **WorldPartition**：引入了 `FFixedGridInfo` 访问器，用于在编辑器时获取固定网格的元数据；为 ISM 运行时单元转换器添加了 `bStrictBucketing` 选项。
- **PCG**：为与编辑器交互的特定节点添加了事务支持（仅用于关卡资产图），并可通过 cvar 控制；添加了对类型擦除的 `Get/SetRange` 的支持；在数据覆盖面板列表视图的右键菜单中启用了清除增量的功能；修复了八叉树因 NaN 值而可能爆炸的问题。
- **动画**：为动画录制添加了 `bRemoveExcludedCurves` 选项，用于移除已录制但希望排除的曲线；为 Mass 表示添加了分层动画支持；为动画序列添加了同步元数据生成功能；为配置混合添加了根空间支持；为 UAF 分层添加了动画节点支持。
- **Sequencer**：将累积的根运动传递给根骨骼，用于分层控制 rig 等任务；添加了装饰和装饰区段的复制/粘贴功能；将 `AddDefaultTracksForActor` 移动到 `ULevelSequenceEditorSubsystem` 的公共方法中，以便其他工具可以应用项目设置的默认轨道。
- **模块化视口**：添加了辅助游戏实例和场景视口 UMG。
- **Lumen**：添加了屏幕探针收集的可视化功能。
- **导航系统**：在 `UNavigationSystemV1` 中添加了 `GetSupportedAgentNames()` 函数，可与 `UPROPERTY(meta=(GetOptions=))` 配合使用，以获取所有可用代理名称的下拉列表。
- **曲线编辑器**：增强了将多条曲线粘贴到多条曲线的功能。
- **CDO**：添加了设置 CDO 覆盖的功能。
- **DNA 资产**：实现了用于将 DNA 资产从嵌入在 SkelMesh 状态和旧版 UDNA 版本迁移到最新 UDNA 类型的命令行工具。
- **ZenStoreWriter**：允许在烹饪期间为每个生成的 bulkdata 载荷写出元数据。
- **世界/关卡实例**：在 `FLevelUtils::ApplyLevelTransform` 中添加了对绝对标志的支持。
- **TedsFolders**：为 Actor 和文件夹行添加了 `FRootObjectColumn` 列。
- **源代码控制**：在版本控制窗口的“类型”列中添加了 Verse 文件支持。
- **多阶段处理**：实现了多阶段处理功能。
- **PlainProps**：添加了新的工具函数 `GetIoChunkTypeFromFlags`，用于根据给定的 `EBulkdataFlags` 集合返回预期的 `EIoChunkType`。
- **PlainProps**：允许 plain-props 重保存命令行工具在未启用 pp-hooks 的情况下运行。
- **Mutable**：添加了骨骼网格变换节点及其在骨骼层级中的支持。
- **Live Link Hub**：允许用户在启动时指定为 Live Link Hub 启用哪些插件。
- **PVE**：添加了通过预览场景设置选项卡更改背景颜色的选项。
- **漫射环境捕获**：升级了漫射环境捕获功能。
- **Horde**：将 OpenTelemetry 包升级到 1.15.x，并在共享 props 中集中管理版本。

## 🚀 重大变更
- **TedsOutliner**：将 `TedsOutlinerMode` 与 `FFolderTreeItem` 解耦。
- **构建工具**：将 MSVC 组件移动到正确版本的 Visual Studio 的建议列表中。
- **着色器缓存**：将 `GlobalShaderCache` 更改为 64 位序列化。
- **Horde**：将 OpenTelemetry 包升级到 1.15.x，并在共享 props 中集中管理版本。
- **Live Link Hub**：防止 Hub 接受自定义时间步长，以避免低时间步长率影响视频和实时求解动画数据的处理。Hub 现在会向客户端发送应使用的 `CustomTimestep` 消息，但自身不会采用。

## ⚡ 性能优化
- **VEUV**：在图表接缝奇异路径中实现了每顶点体素关联，使 `AssignVertexUVs` 进行插值而非外推图表笼。
- **UnrealBuildTool**：在 UBA 中注册规范路径，并将目录路径建模为 `DirectoryReference` 而非字符串，可防止因注册多个大小写不同的路径而导致的罕见崩溃问题。

## 🐛 Bug 修复
- **MeshTerrain**：修复了在 ITF 修复属性缓存恢复后，本地解决方法与基类属性缓存 ID 冲突的问题。
- **Teds**：修复了调试器/发现功能。
- **Metahuman 纹理**：修复了当 `PlatformData` 在异步构建线程运行时被设置为 `nullptr` 时可能导致的崩溃。
- **MoviePipeline**：推测性修复了 `UMoviePipelinePIEExecutor` 中一个罕见的崩溃，该崩溃可能在渲染期间队列发生变更时发生。
- **虚拟阴影贴图**：修复了 `VirtualShadowMapCacheManager` 调试代码中 `FAppTime` 的断言问题。
- **集群联合**：修复了其内部加速结构的竞态条件。
- **材质**：修复了 `test_set_and_get_static_switch_parameter` 测试中 `FMaterial::~FMaterial()` 的断言失败。
- **Nanite**：修复了 Nanite 组装中“为实例化优化”的问题。
- **语义搜索**：修复了在非 AI 搜索模式下仍显示语义搜索分数的 UI 错误。
- **Niagara**：为 `FStackIssue` / `FStackIssueFix` 唯一标识符使用了独立于区域设置的标识。
- **Sequencer**：修复了模块化控制 rig 的首次关键帧设置会丢失选择的问题。
- **动画数据**：修复了 `UAnimSequencerController::RemoveBoneTracksMissingFromSkeleton()` 中的断言崩溃。
- **PCG**：修复了八叉树因 NaN 值而可能爆炸的问题。
- **AutoRTFM**：如果未调用 `autortfm_initialize()`，则 `autortfm_shutdown()` 现在为空操作。
- **Recompute Point Scale 节点**：添加了缺失的工具提示。
- **文件沙箱**：修复了重置已删除文件时间戳的问题。
- **CoreUObject**：修复了 `ProcessNewlyLoadedUObjects` 广播 `ECompiledInUObjectsRegisteredStatus::PreCDO` 的时机，使其在所有结构体注册并链接之后、创建 CDO 之前立即发生。
- **Mutable**：修复了骨骼网格引脚的多个问题。
- **SLW**：在启用前向渲染时，禁用了 SLW 深度预处理通道的速度输出。
- **PCG**：确保纹理引脚上的多数据为 false，因为多数据在 GPU 上使用时会创建大量采样器。
- **定时器**：在事务中设置 `TimerIndicesByObjectKey`，以处理指向需要迁移到服务器的远程对象的情况。
- **关卡实例**：修复了编辑器内父级展平的问题，其中子级具有绝对标志的变换应在容器变换之前应用，而容器变换会忽略这些标志。
- **Android EGL**：在调整表面大小后重新设置 EGL 上下文。
- **PlainProps**：调整了关于非链接结构体的新断言，使其仅对非瞬态结构体触发。
- **UEMHC**：修复了导出工具属性编辑的撤销问题。
- **UEMHC**：修复了服装工具中结构体子属性编辑的应用问题。
- **UEMHC**：修复了加载光照环境时背景颜色的应用问题。
- **热修复**：修复了当不存在后端热修复时，某些烘焙热修复不会应用的问题。
- **着色器**：修复了进程内着色器编译回退在管道重试时损坏 `Job.Input.Environment` 的问题，并完善了现有检查。
- **Linux**：修复了游戏手柄断开通知中用户/设备 ID 不断增加的问题。
- **网络驱动程序**：修复了当启用 `net.EnableActorCountInStats` cvar 时，网络驱动程序统计信息现在可与 Iris 一起工作的问题。
- **着色器 PSO 预缓存**：允许在着色器数据不可用时优雅地失败。
- **动画**：修复了将加法动画类型设置为局部空间会影响曲线数据的问题。
- **编译**：修复了在 Shipping 配置中的编译错误。

## 🔧 API 变更
- **InteractiveToolsFramework**：修改了 `UInteractiveToolPropertySet::SaveRestoreProperties`，使其仅在保存时实例化属性缓存条目。
- **UnifiedError**：重构并简化了公共 API，提供了一种规范的方式来声明和使用错误。
- **Sequencer**：将 `AddDefaultTracksForActor` 移动到 `ULevelSequenceEditorSubsystem` 的公共方法中，以便其他工具可以应用项目设置的默认轨道。

## ⚠️ 废弃预告
- **Live Link Hub**：移除了对实验性插件设备的引用。
- **MoviePipeline**：从 MRQ 中移除了累积景深 (ADOF) 支持。MRQ 中的 ADOF 支持是临时的；ADOF 将仅通过 Graph 和 Basic 配置提供。
- **构建工具**：废弃了 `WindowsTargetRules` 中的 `bStrictPreprocessorConformance`，因为引擎无法在不严格遵守预处理器的情况下编译。
- **Live Link Hub**：移除了定时数据监控功能。
