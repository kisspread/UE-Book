# 2026年10月引擎更新月报

## ✨ 新功能

- **Gaussian Splat**：合并 UE6 Main 的 Gaussian Splat 工作至 UE5 Main（共 7 个批次），引入/更新 Gaussian Splat 渲染与编辑支持。
- **UAF**：新增 output variables 与 typed write bindings；`FBindableContainer` 通过 property bag 支持 object、struct 等类型的 bindable arrays；bindable details picker 支持选择结构体变量中的 enum member，并显示 `UserDefinedStruct` 成员显示名。
- **UAF**：新增 AnimNode descriptor hooks 用于 validation 和 upgrade；允许 module component 过滤 system output pose；新增 system output phases 与默认 injection site 的静态 introspection；Layer Stack UI 改进；`AnimSequenceBase` 加入允许类型列表；支持通过 `FArchive` 捕获和恢复 anim node tree state。
- **UAF**：支持从资产引用播放 Layer Stack；所有 UAF Workspace 资产类型提供视口预览；新增可在代码中构建 Node Description Tree 的资产；层内容有效性变化时自动淡入淡出；Slot 驱动的基础层允许使用 Override Asset Slot 层；Layer Stack 已注册到 Anim Node Factory。
- **UAF**：Graph Action Menu 搜索匹配节点 `Keywords` 元数据；Motion Matching 节点 UX 改进；Bindable object picker 支持 `RequiredAssetDataTags`；AnimGenController 新增 notify 支持；AnimDatabase 新增 `FindAttribute`；新增对 AnimOp 输出 NaN 和非规范化旋转的校验；`ApplyAdditiveSpace` 支持 weight 大于 1.0 时外推 bound/unbound 值；AnimNode 强制子条目在动画树图中声明的 base。
- **UAF**：新增 Chooser 编辑器脚本库，并将 Chooser 表编辑暴露给 Python；Chooser 表支持 Gameplay Tag 与原生共享结构体成员绑定；新增变量监视窗口（Variable Watch Window），支持通过控制台命令进行变量覆盖；新增 Planned Alignment Warp AnimNode；Motion Matching 节点将 `EventToSearch`、`Availabilities`、`PlayRate`、`bKeepInteractionAlive` 及 warp 属性设为可绑定；新增查询绑定到变量的通知窗口 Blueprint 库；Align Warp notify 增加 `bWarpRotation` 和 `bWarpTranslation`；函数绑定与调用函数节点支持传递参数；StateTree 节点选择器新增 `a.UAF.StateTree.HideUnsupportedNodes` CVar（默认开启）以隐藏不支持节点；Layer stack 为变量分配 Asset Instance。
- **UAF / AnimMixer**：Mixer Tree 的逐帧值可绑定到 UAF 变量，并能从系统资产解析 UAF target 路由（无其他路由时接管系统输出）。
- **Chooser**：`UChooserTable` 和 `UProxyAsset` 可引用共享的 `UChooserSignature` 资产；随机化 Chooser 上下文结构体已暴露给 UAF。
- **Control Rig**：首次实现 modular rig projection 的浅层版本；新增知识库模块及节点目录；Anim Sequence Bake To Control Rig 使用与 Sequencer 一致的 Rig Picker；Double 变量支持映射到 Anim Curves；Modular Rig 变量支持 Verse 往返；Collapse All Layers 采用共享代码自顶向下合并区段，并新增“从选中轨道创建 Anim Layers”选项；Sequencer 支持复制粘贴 Space Channels。
- **Control Rig / Sequencer**：Control Rig Sequencer 库新增 `AddAutoBakeWithAnimSequences`，可链接并自动烘焙到预创建动画序列；Sequencer Anim Mixer 支持 Control Rig 烘焙时不弹出选项对话框；Mixer 层、节与装饰 outliner 行获得独立标识符；outliner 脚本支持锁定、静音和停用行。
- **RigVM / Curve Editor / Gizmos**：RigVM 拖拽变量到输出引脚会自动添加 Set 节点；Curve Editor 为 broken tangents 新增 Lock Tangent 切换，可通过工具栏按钮或默认热键 E 锁定 arrive 和 leave tangent 的角度与权重共同编辑，并支持在选中不同类型关键帧时编辑时间和值；Gizmos 新增 Camera Space Nudge 热键。
- **Sequencer**：在 `ISequencer` 和 Level Sequence Editor blueprint library 中新增 `GetDirectlySelectedFolders`；粘贴 Sections 到 blendable track 时，重叠区域现在会被替换，而不是堆叠隐藏副本。
- **PoseSearch / MotionWarping**：PoseSearch 新增 `FAsyncPoseSearchDatabasesManagement::OnAsyncBuildIndexCompleted` 回调；PoseSearchInteractionAsset 调试绘制改进；`ExtractLocalSpacePose` 支持 `UAnimComposite`，并避免对未处理资产返回未初始化骨骼变换；MotionWarping 新增 `VectorFromTargetToOwner2D` offset direction，新增在 motion warping notify 开始时缓存目标的选项，并支持负偏移。
- **HWRT / Nanite Ray Tracing**：HWRT 支持 Nanite assembly parts 作为 append instances 实例化到 TLAS，append instances 超预算时新增日志和屏显警告；Nanite Ray Tracing 为 `BLASClusterCountBuffer` 添加 `EBufferUsageFlags::SourceCopy`。
- **Nanite 半透明**：支持前层渲染、编辑器选择与拾取，且无 Splat 时无 AVBOIT 开销。
- **ASTP Anim Sequence Transform Provider**：新增 mirroring、root motion、stateless track playback 支持，并修复 exact bounds 与 lifecycle 问题。
- **Dataflow**：`TransferMeshAttributes` 合并 Main 的 inpainting 并转移默认 polygroup。
- **Switchboard / Sony SDK**：Switchboard 枚举未连接设备的本地 VP roles；Sony SDK 新增对 SDK 14 的支持，最高版本仍默认为 SDK 13。
- **RewindDebugger**：预览网格与动画类改为异步加载。

## 🚀 重大变更

- **UAF**：node transitions 改为必需，并新增 Instant Transition。
- **UAF**：默认 bone transform type 改为 VQVd。
- **UAF Runtime**：移除 Inline Anim Node 支持，使用内联节点的项目需迁移到外部节点资产。
- **AIE Smart Compensation**：`Sequencer.SwitchBoundary.OccupiedLandingMode` 默认值从 2 改为 3，并改进同 boundary 上相邻 constraint keys 的补偿逻辑。
- **HWRT**：移除 5.8 已废弃的代码；移除未使用的 `bApplyLocalBoundsTransform` 路径。

## ⚡ 性能优化

- **MovieScene / Sequencer / Control Rig**：优化 Editor keying 和 curve-channel tangent 性能；在单一 bake session 中重建 anim mixer root motion offset cache；缓存序列层级是否有未保存更改，用于保存按钮图标显示，减少重复检查；优化多控件选中时的关键帧设置（Set Key 和 S），提高操作速度。
- **RigVM**：cook 编译去重、图验证/内联缓存、AST 代理指针哈希、`ClearInvalidReferences` 提前返回。
- **UAF**：Anim Node 销毁拆分为两个阶段，降低单次销毁集中开销；移除 blend AnimOps 中冗余的 normalize 调用；Layering 从缓存 pose 读取 layer input，减少重复计算。
- **RigLogic**：反序列化后释放未使用的内存，降低内存占用。
- **RewindDebugger**：预览网格和动画类异步加载，减少编辑器阻塞。
- **Nanite / HWRT**：Nanite 半透明在无 Splat 时不产生 AVBOIT 开销；修复无程序化像素着色器时自定义插值器/UV 导致的冗余光栅化仓；Nanite Ray Tracing 用 per-part capacity vector 取代原先基于 `GetNumBLAS` 与 `NumResidentClusters` 的 CLAS 地址预留，改由 hierarchy traversal 实际输出的 cluster 数量通过 readback 提供；HWRT 更新更多 `GetDynamicRayTracingInstances` 实现以使用 GPUScene，避免手动提交 `InstanceTransforms`。
- **LumenRadiosity**：修复 SceneCapture2D 渲染时 Lumen indirect lighting atlas 每帧被清除的问题，避免不必要的性能开销。
- **DynamicWind**：改善剔除诊断，并减少 shader permutations；将参数化风模式（`DynamicWind.Mode 0`）改为无状态，以适配低端硬件。
- **nDisplay**：移除 `UDisplayClusterViewportClient::Draw` 中重复的 `UpdateLevelStreaming` 调用。
- **Cook 确定性**：Package Access Tracking 修复使依赖记录不再依赖加载顺序/进程。
- **TEDS Compat**：immediate mode 下批量移除 UObject rows，按批次触发 observers 并 flush commands。

- **UAF**：`FAnimNextInjectionRequestArgs` 成员改为 public，允许在 UAF 外部构建自定义 injection request。
- **UAF**：`FBindableContainer` 支持 object、struct 等类型的 bindable arrays；bindable import text parsing 支持读取 plain values。
- **UAF Layering**：Layer Content 输入源由 `PreviousLayerOutput` 重命名为 `NestedInput`。

- **Sequencer**：`ISequencer` 和 Level Sequence Editor blueprint library 新增 `GetDirectlySelectedFolders`；Scripting API 的 `GetBoundObjects` 与 `GetObjectBindings` 防护空输入并在请求帧求值。
- **AssetTools**：移植 rename 前置 delegate，引擎侧支持资产重命名前回调。
