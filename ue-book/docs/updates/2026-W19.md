## ✨ 新功能
- **PCG (Procedural Content Generation)**: 为 Biome Core 添加了在父图级别设置骨骼网格体生成器 Transform Provider 数据资产引用的能力；支持类型擦除的 Get/SetRange 操作；为与编辑器交互的特定节点添加了事务支持（可通过 cvar 控制）；在数据覆盖面板列表视图中启用了从右键菜单清除增量的功能；确保纹理引脚上的 multi-data 为 false，以避免在 GPU 上创建过多采样器。
- **Material & Rendering**: 为 MaterialIR 自定义输出添加了表达式 getter 支持；新材质翻译器支持 Sparse Volume Texture；为 Lumen 添加了屏幕探针收集可视化功能；为配置文件混合添加了根空间支持；实现了漫射环境捕获的升级。
- **Animation & Sequencing**: 为动画录制添加了 `bRemoveExcludedCurves` 选项，用于移除已录制但希望排除的曲线；为 AnimSequence 添加了同步元数据生成；为 Sequencer 添加了将累积根运动馈送到根骨骼的功能（用于分层控制 rig）；为曲线编辑器添加了将多个曲线粘贴到多个曲线的额外功能；为 Sequencer 添加了装饰和装饰部分的复制/粘贴功能；为 Mass Representation 添加了分层动画支持；为 UAF Layering 添加了动画节点支持。
- **World & Level Management**: 为 WorldPartition 引入了 `FFixedGridInfo` 访问器，用于编辑器时的固定网格元数据；在 WP ISM 运行时单元转换器上添加了 `bStrictBucketing` 选项；为 `FLevelUtils::ApplyLevelTransform` 添加了对绝对标志的支持。
- **Tools & Editor**: 为 TedsFolders 添加了为 actor 和文件夹行填充的 `FRootObjectColumn`；为模块化视口添加了辅助游戏实例和 Scene Viewport UMG；为 PVE 添加了通过预览场景设置选项卡更改背景颜色的选项；允许用户指定在启动时为 Live Link Hub 启用哪些插件；为 `UNavigationSystemV1` 添加了 `GetSupportedAgentNames()`，用于生成可用代理名称的下拉列表。
- **Build & Infrastructure**: 创建了 `r.Shaders.ForceOptimizeRaytracing` 控制台变量；实现了执行 DNA 资产迁移的命令行工具；允许 ZenStoreWriter 能够写出在烹饪期间生成的每个 bulkdata 有效负载的元数据。
- **Mutable**: 添加了“骨骼网格体在骨骼层次结构中的变换”节点。
- **其他**: 为 InteractiveToolsFramework 添加了设置 CDO 覆盖的功能。

## 🚀 重大变更
- **UnifiedError**: 重构了公共 API，将其减少到一种规范的方式来声明和使用错误。
- **Movie Render Queue (MRQ)**: 从 MRQ 中移除了累积景深 (ADOF) 支持，该功能将仅通过 Graph 和 Basic 配置提供。
- **LiveLinkHub**: 移除了定时数据监控功能。
- **Shaders**: 将 GlobalShaderCache 更改为 64 位序列化。

## ⚡ 性能优化
- **InteractiveToolsFramework**: 修改了 `UInteractiveToolPropertySet::SaveRestoreProperties`，仅在保存时实例化属性缓存条目。
- **UnrealBuildTool (UBA)**: 在 UBA 中注册了规范路径，并将目录路径建模为 `DirectoryReference` 而不是字符串，以防止在注册具有不同大小写的多个路径时出现罕见的崩溃问题。

## 🐛 Bug 修复
- **PCG**: 修复了重命名嵌入式子图菜单中的本地化标签冲突。
- **Landscape**: 修复了批量合并时部分更新（仅更新某些组件）在上边界和最左边边界出现的像素行/列缺失问题。
- **WorldPartition**: 修复了 LI actor 指针/软引用覆盖的问题。
- **Mesh Partition**: 修复了在解析修改器层行时，当存在最近删除的层行的陈旧映射时出现的 ensure 错误。
- **MeshTerrain**: 修复了属性缓存 ID 与基类冲突的本地变通方法。
- **Teds Debugger**: 修复了发现功能。
- **Virtual Shadow Maps (VSM)**: 修复了 `VirtualShadowMapCacheManager` 调试代码中的 `FAppTime` ensure 错误。
- **Physics**: 修复了集群联合内部加速结构的竞态条件。
- **Materials**: 修复了 `test_set_and_get_static_switch_parameter` 测试中的 `FMaterial` 析构函数断言。
- **Nanite**: 修复了 assembly 的“优化实例化”问题。
- **VEUV**: 修复了图表接缝奇异路径的逐顶点体素关联，使 `AssignVertexUVs` 插值而非外推图表笼。
- **Semantic Search**: 修复了语义搜索 UI 中分数在非 AI 搜索模式下仍然显示的错误。
- **Niagara**: 使用与区域设置无关的标识符修复了 `FStackIssue` / `FStackIssueFix` 的唯一 ID。
- **Sequencer**: 修复了模块化控制 rig 的第一次关键帧丢失选择的问题。
- **Animation**: 修复了动画数据中的崩溃断言；修复了设置为局部空间的加法动画类型影响曲线数据的问题。
- **Linux**: 修复了游戏手柄断开通知中不断增加的用户/设备 ID。
- **Networking**: 修复了当启用 `net.EnableActorCountInStats` cvar 时报告的 NetDriver 统计信息现在与 Iris 一起工作。
- **Shaders**: 修复了进程内着色器编译回退在管道重试时损坏 `Job.Input.Environment` 的问题。
- **Hotfix**: 修复了在没有后端热修复时某些烘焙热修复不应用的问题。
- **UEMHC (MetaHuman Creator)**: 修复了导出工具属性编辑的撤销问题；修复了服装工具的结构子属性编辑；修复了加载照明环境时背景颜色的应用。
- **Android**: 修复了在调整表面大小后 EGL 上下文未重新设置的问题。
- **PlainProps**: 调整了关于非链接结构的新断言，使其仅对非瞬态结构触发。
- **Movie Pipeline**: 推测性修复了在渲染期间队列发生变异时 `UMoviePipelinePIEExecutor` 中罕见的崩溃。
- **Metahuman**: 修复了在异步构建线程运行时 `PlatformData` 设置为 nullptr 可能发生的崩溃。
- **Level Instance**: 修复了编辑器中父级展平的问题，其中具有绝对标志变换的子级应在容器变换之前应用。
- **其他**: 修复了 `AttemptedDownload` 的错误格式字符串和字段名不匹配；移除了分屏中不正确的检查；重新引入了被错误删除的 getter；修复了 shipping 版本中的编译错误。

## 🔧 API 变更
- **WorldPartition**: 引入了 `FFixedGridInfo` 访问器，用于编辑器时的固定网格元数据。
- **UnifiedError**: 重构并统一了错误声明和使用的公共 API。

## ⚠️ 废弃预告
- **UnrealBuildTool**: 弃用了 `WindowsTargetRules` 中的 `bStrictPreprocessorConformance`，因为引擎无法在没有严格预处理器一致性的情况下编译。
- **LiveLinkHub**: 移除了对实验性插件设备的引用。
