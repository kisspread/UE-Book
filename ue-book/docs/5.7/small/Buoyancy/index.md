# Buoyancy

> Set of tools for adding buoyant behavior to objects which interact with water bodies generated by the Water plugin

| 属性 | 值 |
|---|---|

| 分类 | Water |

| 实验性 | ⚠️ 是 |

## 用途

Buoyancy 插件为 Chaos 物理系统中的刚体提供真实的浮力模拟。它利用 Water 插件生成的水体（River、Lake、Ocean）作为流体环境，精确计算物体浸没部分的体积与中心，并施加对应的浮力、阻力和海浪作用力。该插件还支持基于样条线的水位采样、浅水仿真网格（Shallow Water Simulation）以及每粒子单独的水面碰撞事件回调，使得复杂形状的物体（如船只、漂浮物）能获得细腻的流体交互效果。

## 使用场景

- 需要为船只、浮标、游泳角色添加逼真浮力行为的游戏（航海、水下探索模拟）
- 需要与 Water 插件生成的水面（河流、湖泊、海洋）进行物理交互的任何项目
- 需要每帧检测物体是否浸水并触发事件（如溅水、水花效果、声音）的复杂交互系统

## 蓝图用法

插件主要面向 C++ 集成，但提供了一大组 `BlueprintImplementableEvent` 接口，让蓝图能够响应水面接触事件。

### 核心事件接口

实现 `BuoyancyEventInterface` 下的 `OnSurfaceTouchBegin`、`OnSurfaceTouching`、`OnSurfaceTouchEnd` 事件，即可在物体与水面接触时获得回调。

| 事件 | 说明 | 所在接口 |
|---|---|---|
| `OnSurfaceTouchBegin` | 物体首次接触水面时调用（对应浸入开始） | `IBuoyancyEventInterface` |
| `OnSurfaceTouching` | 物体持续接触水面时每帧调用 | `IBuoyancyEventInterface` |
| `OnSurfaceTouchEnd` | 物体完全脱离水面时调用（浸没结束） | `IBuoyancyEventInterface` |

这三个事件都提供：水面 Actor（`AWaterBody`）、水面组件、浸没组件、浸没体积、浸没质心、浸没速度，可用于实现泡泡、水花等视觉效果。

### 项目设置

打开“项目设置 -> Buoyancy”面板（`UBuoyancyRuntimeSettings`），可以调整以下核心参数：

| 设置 | 说明 |
|---|---|
| 启用浮力（bBuoyancyEnabled） | 是否运行浮力子系统 |
| 保持浮动物体唤醒（bKeepFloatingObjectsAwake） | 防止物体因物理休眠而失去浮力 |
| 水密度（WaterDensity） | 默认 1 g/cm³ |
| 水阻力（WaterDrag） | 模拟粘滞阻力的无量纲系数 |
| 水面碰撞回调标志（SurfaceTouchCallbackFlags） | 位掩码，控制触发哪些事件（Begin/Continue/End） |
| 最小触发速度（MinVelocityForSurfaceTouchCallback） | 物体相对水面必须超过此速度才触发回调 |

## C++ 用法

### 头文件引入

```cpp
#include "BuoyancySubsystem.h"
#include "BuoyancyEventInterface.h"
```

### 基本用法

要让一个刚体参与浮力计算，需要为它注册浮力数据。以下示例展示在 Actor 中如何通过 `FBuoyancySubsystem` 为物理体添加浮力：

```cpp
// 来源：Engine/Plugins/Experimental/Buoyancy/Source/Runtime/Private/BuoyancySubsystem.cpp
// 在 Pawn 或 Character 中：
UBuoyancySubsystem* BuoyancySubsystem = UWorld::GetSubsystem<UBuoyancySubsystem>(GetWorld());
if (BuoyancySubsystem)
{
    // 为当前 Actor 的 Chaos 刚体注册浮力数据
    FBuoyancyData Data;
    Data.bUseSubdivisions = true;
    Data.MaxNumBoundsSubdivisions = 2;
    Data.CustomGeometry.bUseComplexCollisionAsMesh = true;
    BuoyancySubsystem->RegisterBuoyancyData(/* Chaos physics proxy */, Data);
}
```

### 进阶用法

实现 `IBuoyancyEventInterface` 以接收浸水事件：

```cpp
class AMyFloatingActor : public AActor, public IBuoyancyEventInterface
{
public:
    virtual void OnSurfaceTouchBegin_Native(
        UPrimitiveComponent* WaterComponent,
        UPrimitiveComponent* SubmergedComponent,
        float SubmergedVolume,
        const FVector& SubmergedCenterOfMass,
        const FVector& SubmergedVelocity) override
    {
        UE_LOG(LogTemp, Log, TEXT("开始浸入水面，浸没体积=%f"), SubmergedVolume);
    }

    virtual void OnSurfaceTouching_Native(
        UPrimitiveComponent* WaterComponent,
        UPrimitiveComponent* SubmergedComponent,
        float SubmergedVolume,
        const FVector& SubmergedCenterOfMass,
        const FVector& SubmergedVelocity) override
    {
        // 持续更新
    }

    virtual void OnSurfaceTouchEnd_Native(/* ... */) override
    {
        UE_LOG(LogTemp, Log, TEXT("完全脱离水面"));
    }
};
```

然后通过 `BuoyancySubsystem->SetBuoyancyEventInterface(this, PrimitiveComponent)` 绑定接口。

## Demo 示例

### BuoyantBox.h

```cpp
#pragma once

#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "BuoyancyEventInterface.h"
#include "BuoyantBox.generated.h"

UCLASS()
class ABuoyantBox : public AActor, public IBuoyancyEventInterface
{
    GENERATED_BODY()

public:
    ABuoyantBox();

protected:
    UPROPERTY(VisibleAnywhere)
    class UStaticMeshComponent* MeshComp;

    virtual void BeginPlay() override;

    // IBuoyancyEventInterface
    virtual void OnSurfaceTouchBegin_Native(
        UPrimitiveComponent* WaterComponent,
        UPrimitiveComponent* SubmergedComponent,
        float SubmergedVolume,
        const FVector& SubmergedCenterOfMass,
        const FVector& SubmergedVelocity) override;

    virtual void OnSurfaceTouching_Native(
        UPrimitiveComponent* WaterComponent,
        UPrimitiveComponent* SubmergedComponent,
        float SubmergedVolume,
        const FVector& SubmergedCenterOfMass,
        const FVector& SubmergedVelocity) override;

    virtual void OnSurfaceTouchEnd_Native(
        UPrimitiveComponent* WaterComponent,
        UPrimitiveComponent* SubmergedComponent,
        float SubmergedVolume,
        const FVector& SubmergedCenterOfMass,
        const FVector& SubmergedVelocity) override;
};
```

### BuoyantBox.cpp

```cpp
#include "BuoyantBox.h"
#include "BuoyancySubsystem.h"

ABuoyantBox::ABuoyantBox()
{
    PrimaryActorTick.bCanEverTick = true;
    MeshComp = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("Mesh"));
    SetRootComponent(MeshComp);
    MeshComp->SetSimulatePhysics(true);
    MeshComp->SetCollisionEnabled(ECollisionEnabled::QueryAndPhysics);
}

void ABuoyantBox::BeginPlay()
{
    Super::BeginPlay();

    UBuoyancySubsystem* BuoyancySubsystem = UWorld::GetSubsystem<UBuoyancySubsystem>(GetWorld());
    if (BuoyancySubsystem && MeshComp)
    {
        // 注册浮力数据：使用复杂碰撞网格进行精确浸没计算
        FBuoyancyData Data;
        Data.bUseSubdivisions = true;
        Data.CustomGeometry.bUseComplexCollisionAsMesh = true;
        BuoyancySubsystem->RegisterBuoyancyData(MeshComp->GetBodyInstance(), Data);

        // 绑定事件接口
        BuoyancySubsystem->SetBuoyancyEventInterface(this, MeshComp);
    }
}
```

## 模块依赖

要使用此插件，你的模块（或游戏目标）需要在 `.Build.cs` 中添加以下依赖（省略常见依赖：Core、CoreUObject、Engine、Slate、UMG、InputCore 等）：

| 模块 | 用途 |
|---|---|
| `Water` | 提供水体组件和样条线数据 |
| `ChaosUserDataPT` | 提供物理线程的用户数据管理，用于传递水位信息 |
| `Chaos` | Chaos 物理引擎核心（浮力算法直接使用 Chaos 类型） |
| `PhysicsCore` | 物理设置与碰撞通道 |
