# 2026-06-29 引擎周报

## ✨ 新功能

- **构建管线工具（BPT）功能增强**：开放加密状态查询，可使用 `-ListBinaries` 自行查看；新增 UploadBinary 的 dry-run 模式与 UI 字段校验；UploadBinary 支持热修复（hotfix）；在 UI 中加入反馈按钮与帮助链接。
- **构建管线服务（BPS）**：改进了不可恢复 CDN 截断导致“文件大小不正确”的处理逻辑，使 Chunk 上传更稳定。
- **Lumen 场景更新**：新增基于裁剪球体的卡片剔除与分辨率计算选项。在该模式下卡片 texel 密度保持恒定，可避免连续缩放带来的光照抖动，适合世界空间探针分辨率较低或使用 irradiance field gather 的场景。
- **Composure**：新增“Render Target Extraction”手动提取 Pass，允许在不修改管道的前提下提取渲染目标；现已将 Media Pass / Layer Pass 属性提示显示在 plate pass-tree 组头上。
- **Rivermax**：SDK 从 1.71.30 部分升级至 1.90.18。
- **源代码管理（SCC）**：新增依赖验证软引用支持，由编辑器设置 `EnableValidatingSoftDependencies` 控制。
- **PCG**：为追踪管理器新增对象替换功能。
- **Motion Design**：引入 ClonerEffector。
- **UAF（通用动画框架）**：新增编译时 bindable-value 绑定校验；引入 bindable-value 属性遍历；Notify Foundation 支持跨 VM 事件调度及抽象骨架标签绑定值读取；编辑器支持用户自定义结构体/枚举（UDS/UDE）。
- **MetaHuman**：MetaHumanGenerator 工具集注册现依赖可选内容可用性；管理器中子项排除 UI 可滚动，禁止对 MetaHuman Assemblies 的多选，并恢复展开导航区域时自动选中第一项。
- **平台支持**：新增 Windows 下启动 iOS 构建所需的 go-ios 应用；为 scudo 内存追踪库添加 16k 页大小支持；添加 Android 下构建 openxr_loader 的脚本。
- **渲染**：默认在 Valve Frame Lepton 设备上启用 PSO 预缓存。

## ⚡ 性能优化

- **Wasapi 音频**：缩小 `DeviceSwapCriticalSection` 的作用范围，仅在交换期间锁定，减少音频线程争抢。
- **TmvMedia**：管道执行优化。
- **EpicWebHelper**：构建时禁用未使用的 ICU 和 EditorOnlyData，减小体积。
- **Mutable**：改进移动平台图像纹理参数的质量和性能；修复因几何体重导入导致的相同 Section 多次添加问题，消除了额外的性能与内存开销。
- **Chaos Cloth**：缓存 `p.ClothPhysics.UseEndTickWait` 控制变量指针，避免每帧查找带来的延迟与性能警告。
