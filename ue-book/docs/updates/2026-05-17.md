# 2026-05-17 引擎周报

## ✨ 新功能
- 暴露 `GaussianSplat` 和 `NiagaraGaussianSplat` 插件。
- 为 `Virtual Shadow Maps` 添加了用于 Receiver Mask 覆盖率和静态页面阴影遮罩的可视化模式。
- 为 `PCG` 节点面板添加了 GPU 友好型节点的徽章标识。
- 为 `Horde` 工具箱添加了系统/浅色/深色主题选择器。
- 在 `MaterialToIR` 中暴露了 `LocalPosition` / `WorldPosition` 辅助发射器。

## 🚀 重大变更
- `ShadowDepthReuse`: 允许冻结阴影深度渲染，并在覆盖设置前持续复用当前已渲染的阴影深度信息。
- `FIoStoreShaderLibraryProcessor` 更新，允许将 Shader 库移动到其他容器。
- 为 `VisualLogger` 添加了独立的、基于类别的过滤层。
- 新 `Material Translator`：为 `FEmitter::SetCustomOutputs` 添加了按输出跳过支持。
- `Control Rig`：对 `Unit Struct` 函数为空的情况进行了防御性修复。
- `Mesh Partition`：修复了 `MeshTerrainMode` 仅在编辑器目标下错误地将 `Mesh Partition` 作为插件依赖的问题。
- `Mesh Partition`：在预览部分重建期间延迟获取 Mesh Terrain Section。
- `PCG` 节点面板现在为 GPU 友好型节点显示徽章。

## ⚡ 性能优化
- `DDC`：在层级结构中跟踪异步请求以修复 `WaitForQuiescence`。
- 更新 `zenserver` 至 v5.8.11。
- 为 `Visual Logger` 的推送至注册表配方进行了去重处理。
- 为定向输入 (DI) 捕获添加了排除模式。
- `PCG`：在预览部分重建期间，延迟获取网格体地形部分。
