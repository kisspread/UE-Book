# 2026年9月引擎更新月报

## ✨ 新功能

- **Motion Warping**：为旋转注入添加缓动函数，并重构 `WarpRotation` 函数以提高可读性。
- **Nanite 半透明与 AVBOIT**：新增 `r.Nanite.AllowTranslucentMaterials` 运行时开关，支持 Nanite 半透明材质，包括将顶点颜色插值到像素着色器、以 masked 方式投射阴影、遵循双面材质属性；引入 Adaptive Voxel-Based Order Independent Transparency（AVBOIT），为 Nanite 和非 Nanite 半透明提供新的顺序无关透明渲染方案。相关 raster link 错误与 translucency bin 崩溃已修复。
- **Nanite Ray Tracing**：新增 CLAS（Compact Linear Allocation System）支持，包括按需构建、未引用页面回收、基于 CLAS 池用量的自动质量缩放，以及与 OMM（Opacity Micro-Map）集成；支持 Nanite Assemblies 光线追踪，包括每个 assembly part instance 独立 BLAS、基于 CLAS 可用性的层级遍历，以及流式遍历中的 assembly 支持。
- **UAF**：为 anim tree 资产添加视口支持；为 Chooser Editor 添加编译按钮支持；添加 workspace outliner 对 anim tree 的支持；添加 chooser 随机化上下文支持。新增 Override Asset Slot、CallFunction 动画节点，以及 `FUAFAnimNode::ReplaceChildren`。将 UAF Transitions 暴露给 Blueprint，为 transition nodes 添加 source/target accessors，新增 overlay modifier base class 以简化 anim node modifier 创作，并支持 proxy asset output structs 绑定 UAF output variables。新增 `ReadPoseFromVariable`、`WritePoseToVariable` 节点及变量选择器作用域过滤。
- **Control Rig / RigVM**：扩展 promise 系统，新增 `FindPromise`、`FindPromisedElementLabel` 等 API，支持通过 label 解析 promise，并扩展 post-construct 派生与解析能力；为动画通道实现 `GetElementTypeToSpawn`。编辑增强包括：rig 首次构建时创建 control shape actors；支持在视口中 marquee 选择 sockets、点击选择 nulls；Anim Details 面板展示 proxy control 下父级的 Animation Channels。Nativization 方面，支持模块和函数库的 nativization，并新增用户自定义结构体和枚举的 nativization；Rig 层级搜索支持 AND / OR / NOT 逻辑表达式；新增复制元素名称和 rig element keys 的选项。
- **Sequencer / Curve Editor**：添加 `Shift+M` 快捷键，在播放头处切换标记而不打开编辑对话框；Simple View 时间轴现在只显示选中的动画细节属性键；引入 Struct decorators，标记帧变为装饰容器；标记锁定行为调整为仅限制移动，其他编辑操作保持允许；Curve Editor 简化过滤器添加 “Keep Only Marks” 或 “Mark Ranges” 选项。
- **Movie Render Pipeline**：新增 PSD 输出支持（单层/多层），对应需启用的 `MovieRenderGraphPSD` 插件；渲染预览窗口新增 “Initializing” UI，在关卡加载、着色器编译期间提供反馈；新增 RHI Resource Snapshot，可在指定帧或 VRAM OOM 时生成显存快照（`.rhiresourcesnapshot`），并集成至 Render Resource Viewer；Console Variable 节点支持字符串型 cvar，并允许一次设置多个 cvar；图变量新增 “Restrict to Job” 属性，可排除 shot 覆盖；含连接属性的节点在细节面板中显示连接状态图标；Deferred Panoramic Renderer 节点新增 180° 全景渲染能力；主图窗口集成渲染队列；EXR 元数据增加系统与 GPU 内存统计。
- **Media / Composure / Composite**：Media 框架新增 10-bit RGB r210 采样与 shader 转换，支持 BlackMagic 采集卡 RGB 4:4:4 格式输入；Composure 新增面向 agent 的编辑器脚本 API；Composite 添加可选的 Chroma Projection keying，与现有 RGB keyer 并存。
- **AIE Smart Compensation**：新增 `Sequencer.SwitchBoundary.OccupiedLandingMode 3` 模式，在移动 switch key 时保持现有世界位置并动态调整偏移；增加 Paste 命令、Save Whole Pose 命令，并集成到 Utility Tab Spawner。
- **程序化植被 PVE**：为程序化植被添加 Mesh LODs 支持，包含 asset version stamp 和 node deprecation gating。
- **ASTP**：新增 per-sequence 与 per-pose GPU instance bounds 及 readback，并添加序列分配 API。
- **Shader Compilation**：支持 mesh shader 输出属性中的嵌套结构体，更新 DXC 二进制以包含对应修复；临时禁用 dual source blending 的 SPIRV decorations，解决 AVBOIT permutations 中的 `partial explicit stage output location assignment` 错误。
- **平台支持**：Windows ARM64 实现原生 ARM64 堆栈遍历，启动正确架构的编辑器可执行文件，更新 nvapi 至 r615；iOS 客户端默认切换到 UIScene 生命周期，避免启动崩溃。
- **其他编辑器与工具**：`PropertyEditor` 的 `FDetailWidgetRow` 支持手动切换 Inline Edit Condition 可见性；动画节点资产选择器提取共享组件，供 Graph editor 与 details panel 复用；IK Rig Retargeting 支持使用不同骨骼的外部姿势。

## 🚀 重大变更

- **PSD SDK 迁移**：PSD SDK 从 PSDImporter 插件移至引擎级通用位置，供 Movie Render Graph 等模块使用，可能影响依赖该插件的现有项目。
- **Control Rig / RigVM Return 节点行为变更**：函数 Return 节点现在默认会退出函数；此前需要手动连接，该变更可能影响现有图表逻辑。
- **UAF 缓存姿势节点重命名与重构**：缓存姿势节点重命名为 “Read Pose From Cache Node”，并进行了缓存姿势逻辑重构。
- **MovieRenderPipeline Collection 节点更新**：对 Collection 节点进行了更新，可能影响现有渲染配置。
- **原生类型 padding 调整**：多个模块和插件减少了原生类型 padding，可能影响内存布局和二进制兼容性。

## ⚡ 性能优化

- **Control Rig**：修复 FK Control Rig 初始化中的二次方开销，显著提升大型控制装备的初始化性能。
- **Substrate 光照**：当没有 rasterized lighting pass 会读取 standalone tile stencil 时（例如所有灯光均由 MegaLights 处理），跳过该 stencil pass，减少不必要的 GPU 开销。
- **Sequencer 交互**：减少拖拽期间的冗余鼠标事件处理，提升拖拽响应性能和流畅度。
- **Nanite Ray Tracing**：BLAS 缓存与 RuntimeResourceId/root page index 解耦，减少缓存误命中；预分配 CLAS 缓冲区；根据页面安装情况跟踪实际所需 block 数，优化内存使用。
- **Editor ToolMenu**：修复 section/entry 引用在重分配后可能悬挂的问题，提升稳定性和性能。

## 🔧 API 变更

- 将已弃用的 `FString(Len, Ptr)` 构造函数替换为 `FString::ConstructFromPtrSize(Ptr, Len)`；移除 ProceduralVegetation 私有头文件和编辑器模块中的死 API 导出。
- `CoreUObject` 新增 `FFieldPath::IsResolved()`，便于判断字段路径是否已解析。
- UAF Runtime 为 transition nodes 添加 source/target accessors，新增 overlay modifier base class，并将 Transitions 暴露给 Blueprint；Proxy Assets 修复 output structs 以支持绑定 UAF output variables；UAF AnimNode 通过 visitor stack 查询描述符接口。
- RigVM 资产现在 nativizes 其自身拥有的函数；RigVM 函数库在 cook 期间编译到编译器自有存储，提高 cook 确定性。
- 新增 `UE_WITH_GC_BARRIER` 宏，可在构建目标中通过 `bWithGCBarrier=true` 移除未启用增量可达性时 `TObjectPtr` 中的 barrier 检查开销。
- 着色器函数 `LinearStep` 移动至 `Common.ush`，影响包含依赖。
- 内部命名与接口调整：`NumAssemblyParts` 更名为 `NumAssemblyTransforms`，`FRayTracingManager` 接口清理，以及 CLAS 相关类型和成员命名优化。
