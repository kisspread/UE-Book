## 用途

`PluginUtils` 插件提供了一套底层的 C++ 工具类 (`FPluginUtils`)，专门用于以编程方式管理虚幻引擎插件的生命周期。其核心功能包括：动态创建新插件（从模板）、加载/卸载已存在的插件、查询插件路径信息以及验证插件名称的有效性。

它主要是为虚幻编辑器内部工具（如“插件浏览器”Plugin Browser）提供底层支持，使得在编辑器扩展或自动化脚本中能够安全、一致地操作插件。

## 使用场景

- **编辑器扩展开发**：你需要开发一个自定义的编辑器工具或窗口，用于批量创建、管理项目中的插件。
- **自动化流程**：在 CI/CD 管道或编辑器脚本中，需要动态生成插件结构或测试插件的加载/卸载。
- **插件浏览器后端**：为 `Plugin Browser` 面板的“新建插件”功能提供核心逻辑。

## 蓝图用法

该插件没有暴露任何 `UFUNCTION(BlueprintCallable)` 或 `UPROPERTY(BlueprintReadWrite)` 接口。它是一个纯粹的 C++ Editor 模块，其 API 通过 `FPluginUtils` 静态函数提供，主要在编辑器 C++ 代码或 Python 脚本（通过 `PythonScriptPlugin`）中使用。

## C++ 用法

### 头文件引入

```cpp
#include "PluginUtils.h"
```

### 基本用法

`FPluginUtils` 提供了大量静态工具函数，主要分为以下几类：

**1. 路径查询函数**
用于获取插件相关的各种目录路径。
```cpp
// 获取插件的根目录
FString PluginFolder = FPluginUtils::GetPluginFolder(TEXT("/Path/To/Parent"), TEXT("MyPlugin"), true);

// 从 .uplugin 文件路径反向获取插件名称
FString PluginName = FPluginUtils::GetPluginName(TEXT("/Path/To/MyPlugin/MyPlugin.uplugin"));

// 获取插件内容目录
FString ContentFolder = FPluginUtils::GetPluginContentFolder(TEXT("/Path/To/Parent"), TEXT("MyPlugin"));
```

**2. 创建与加载**
核心功能，用于创建并立即加载一个新插件。
```cpp
// 定义创建参数
FPluginUtils::FNewPluginParams CreateParams;
CreateParams.CreatedBy = TEXT("My Company");
CreateParams.FriendlyName = TEXT("My Awesome Plugin");
CreateParams.Description = TEXT("This plugin does amazing things.");
CreateParams.bCanContainContent = true;
CreateParams.bHasModules = true;
CreateParams.ModuleDescriptorType = EHostType::Runtime;

// 定义加载参数
FPluginUtils::FLoadPluginParams LoadParams;
LoadParams.bSelectInContentBrowser = true;
LoadParams.bEnablePluginInProject = true;

// 创建并加载插件
TSharedPtr<IPlugin> NewPlugin = FPluginUtils::CreateAndLoadNewPlugin(
    TEXT("MyAwesomePlugin"),
    FPaths::ProjectPluginsDir(), // 插件位置
    CreateParams,
    LoadParams
);

if (NewPlugin.IsValid())
{
    UE_LOG(LogTemp, Log, TEXT("Plugin '%s' created and loaded successfully."), *NewPlugin->GetName());
}
else
{
    UE_LOG(LogTemp, Error, TEXT("Failed to create plugin. Reason: %s"), *LoadParams.OutFailReason->ToString());
}
```

**3. 验证函数**
在创建前验证名称和位置的有效性。
```cpp
FText FailReason;
bool bValid = FPluginUtils::ValidateNewPluginNameAndLocation(
    TEXT("MyNewPlugin"),
    FPaths::ProjectPluginsDir(),
    &FailReason
);

if (!bValid)
{
    UE_LOG(LogTemp, Warning, TEXT("Invalid plugin: %s"), *FailReason.ToString());
}
```

### 进阶用法

**使用带描述符的创建参数 (`FNewPluginParamsWithDescriptor`)**
当你已经有一个完整的 `FPluginDescriptor` 对象（例如从现有插件解析而来）时，可以使用此版本。

```cpp
// 假设我们有一个从其他插件获取的 Descriptor
FPluginDescriptor ExistingDescriptor;
// ... 填充 ExistingDescriptor ...

FPluginUtils::FNewPluginParamsWithDescriptor CreateParamsWithDesc;
CreateParamsWithDesc.Descriptor = ExistingDescriptor;
CreateParamsWithDesc.TemplateFolders.Add(TEXT("/Path/To/MyCustomTemplates"));
CreateParamsWithDesc.NameToReplace = TEXT("MyNewPluginName"); // 替换模板中的 PLUGIN_NAME

FPluginUtils::FLoadPluginParams LoadParams;

TSharedPtr<IPlugin> NewPlugin = FPluginUtils::CreateAndLoadNewPlugin(
    TEXT("MyNewPluginName"),
    FPaths::ProjectPluginsDir(),
    CreateParamsWithDesc,
    LoadParams
);
```

**动态加载/卸载现有插件**
```cpp
// 加载一个已安装但未启用的插件
TSharedPtr<IPlugin> Plugin = FPluginUtils::LoadPlugin(TEXT("SomeExistingPlugin"), FPaths::EnginePluginsDir());
if (Plugin)
{
    // 卸载（仅对纯内容插件安全）
    FText FailReason;
    bool bSuccess = FPluginUtils::UnloadPlugin(Plugin.ToSharedRef(), &FailReason);
}
```

## Demo 示例

下面是一个简单的示例，展示如何在编辑器启动时创建一个带模块的新插件。

```cpp
// MyPluginCreatorCommandlet.h
#pragma once
#include "Commandlets/Commandlet.h"
#include "MyPluginCreatorCommandlet.generated.h"

UCLASS()
class UMyPluginCreatorCommandlet : public UCommandlet
{
    GENERATED_BODY()

public:
    virtual int32 Main(const FString& Params) override;
};

// MyPluginCreatorCommandlet.cpp
#include "MyPluginCreatorCommandlet.h"
#include "PluginUtils.h"
#include "Misc/Paths.h"

int32 UMyPluginCreatorCommandlet::Main(const FString& Params)
{
    // 1. 准备参数
    FPluginUtils::FNewPluginParams CreateParams;
    CreateParams.CreatedBy = TEXT("Commandlet Example");
    CreateParams.FriendlyName = TEXT("Generated Plugin");
    CreateParams.Description = TEXT("A plugin generated by commandlet.");
    CreateParams.bHasModules = true;
    CreateParams.bCanContainContent = false;

    // 假设你的插件模板放在 [Project]/Plugins/Templates/MyTemplate
    CreateParams.TemplateFolders.Add(FPaths::ProjectPluginsDir() / TEXT("Templates/MyTemplate"));

    FPluginUtils::FLoadPluginParams LoadParams;
    LoadParams.bSynchronousAssetsScan = true;

    // 2. 执行创建
    TSharedPtr<IPlugin> NewPlugin = FPluginUtils::CreateAndLoadNewPlugin(
        TEXT("CommandletPlugin"),
        FPaths::ProjectPluginsDir(),
        CreateParams,
        LoadParams
    );

    if (NewPlugin.IsValid())
    {
        UE_LOG(LogTemp, Display, TEXT("Successfully created plugin: %s"), *NewPlugin->GetName());
        return 0; // 成功
    }
    else
    {
        UE_LOG(LogTemp, Error, TEXT("Failed to create plugin."));
        return 1; // 失败
    }
}
```

### 维护评价

`PluginUtils` 是一个维护状态良好的**活跃**插件。从 git 历史看，它在过去一年内有多次功能性更新（如添加新标志、修复编译问题）和代码现代化改进（迁移日志宏）。它作为编辑器核心工具链的一部分，持续得到维护和适配。虽然创建已有约6年，但因其底层工具属性且持续更新，依然是推荐使用的稳定组件。它无已知的重大限制，主要风险在于其 API 可能随引擎版本更新而变化（例如 5.6 中废弃了一个函数重载）。
