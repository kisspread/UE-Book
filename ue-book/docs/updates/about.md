# 关于更新

追踪 Unreal Engine 引擎最新改动，关注插件生态演进。

- **周报**：每周一自动抓取 `ue5-main` 分支最新提交，AI 分析归类，覆盖全引擎
- **月报**：每月初翻译上游月度报告，覆盖全引擎变更

## 鸣谢

月报翻译自 **[@pafuhana1213](https://github.com/pafuhana1213) 的 [UnrealEngine-UpdateTracker](https://github.com/pafuhana1213/UnrealEngine-UpdateTracker)** 项目。

该项目每日追踪 Unreal Engine 私有仓库提交，AI 归类生成报告。月度汇总质量极高，是我们的核心上游。
